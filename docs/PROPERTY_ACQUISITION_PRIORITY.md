# 데이터 확보 우선순위

2026-09-24 사용자 지정. 전국 서비스와 기존 수집 자료를 유지하면서 앞으로의 수집 순서만 변경합니다.

| 순위 | 대상 |
|---|---|
| 1 | 서울·인천: 동일 우선순위 |
| 2 | 경기 남부 |
| 3 | 대전 |
| 4 | 세종 |
| 5 | 청주 |
| 6 | 나머지 경기도·충청남도·충청북도 |
| 7 | 부산·대구·울산·경상북도·경상남도 |
| 8 | 나머지 전국 |

경기 남부는 이 수집 정책에서 수원·용인·성남·부천·화성·안산·안양·평택·시흥·김포·광주·광명·하남·군포·오산·이천·안성·과천·의왕·양평·여주로 정합니다. 기관의 별도 행정 분류를 새로 단정하는 규칙이 아니며 변경 가능한 운영 범위입니다. 시의 구는 동일 순위를 상속합니다. 청주는 청주시 각 구를 포함합니다.

같은 순위에서는 최신 완료 계약월 → 당월 잠정 → 과거월 순입니다. 같은 월에는 지역 코드와 거래 유형 순으로 결정론적으로 처리합니다. 서울과 인천을 모두 해당 월에서 처리한 뒤 이전 월로 갑니다. 상위 순위의 계획된 과거 이력을 먼저 처리하고 하위 순위로 넘어갑니다. 월 필터를 명시한 갱신 실행은 그 월 범위 안에서 동일한 지역 우선순위를 적용합니다.

로컬 Collector, 원격 RemoteCollector, 무료 GitHub Actions의 오프라인 계획이 같은 정책 모듈을 사용합니다. 정책 ID: `capital-south-gyeonggi-chungcheong-20260924`.

이 변경은 기존 완료/빈 응답/실패 상태, 페이지, 스냅샷, API 호출 장부, 지역 코드, 자료 원본을 지우거나 다시 쓰지 않습니다. SQLite 연결의 정렬 함수로 남은 작업을 고르며 체크포인트 스키마는 그대로입니다. 재시도·갱신은 기존 명시적 옵션을 유지합니다. 공개 지도의 초기 지역이나 전국 범위를 특정 지역으로 바꾸지 않습니다.

10년 이력 확보·전국 좌표 검증·자동 수집 활성화·새 데이터 공개는 각각 별도입니다. 우선순위 코드 적용과 수집 계획 생성은 데이터 확보 완료가 아닙니다.
