# 2D 건물·도로의 넓은 확대 범위

기존 서울·인천 상세 자료는 건물과 도로 모두 zoom 14부터 제공됐습니다. 스타일이 아니라 원본 타일 카탈로그의 최소 확대 수준 때문에 축소하면 두 레이어가 사라졌습니다.

`pipeline.map_tiles_regional --extend-display`는 검증된 지역 상세 후보의 원본 인덱스를 읽기 전용으로 재사용합니다. 건물은 zoom 12, 상세 도로는 zoom 13부터 표시할 수 있는 타일을 추가합니다. 기존 전국 도로는 zoom 6부터 계속 제공됩니다. zoom 14의 기존 타일·선택 속성·다른 지도 레이어는 파일 해시가 같은 상태로 보존합니다. 원본 인덱스의 형상·ID·최소 확대 수준도 수정하지 않습니다.

단일 건물 테마를 그대로 확장하면 서울 밀집 구간의 zoom 12 타일에 건물 46,434개가 포함돼 해제 후 2,582,083바이트였으며, 기존 1MiB 제한을 넘었습니다. 다른 밀집 구간은 zoom 13에서도 1,211,330바이트였습니다. 건물을 지우거나 제한을 높이는 대신 원본 ID 해시를 기준으로 네 개의 고정 파티션으로 나눕니다. `buildings-overview-0`부터 `3`까지 각각 zoom 12~13을 제공하며, 지도 스타일은 zoom 14부터 기존 상세 타일로 전환합니다. 원본 윤곽을 추가로 단순화하지 않습니다.

각 추가 확대 수준·파티션마다 모든 원본 ID가 최소 한 타일에 표현됐는지 검사하고, 파티션별 건물 수의 합이 원래 건물 수와 같은지 확인합니다. 아주 작은 형상은 기존 렌더러와 동일하게 윤곽 또는 점으로 표현하며, 원본 형상 해시와 식별자는 보존합니다. 압축 파일과 해제 타일의 1MiB 상한, 타일 묶음 크기 기준, 선택 속성의 출처 계약은 유지합니다. 네 개의 고정 소스가 추가되며 요청 슬롯과 클라이언트 전체 캐시 상한은 기존과 같습니다. 최초 표시량이 늘어난 만큼 실제 브라우저 성능은 별도로 검증해야 합니다.

```powershell
.venv/Scripts/python.exe -X utf8 -B -m pipeline.map_tiles_regional --baseline .local/regional-detail-20260924/seoul-incheon-v3 --output .local/regional-detail-20260926/seoul-incheon-partitioned-overview-v3 --extend-display
.venv/Scripts/python.exe -X utf8 -B -m pytest tests/test_map_tiles_regional.py -q
```

저줌 파티션의 `detail_topic_id: buildings`는 원래 건물 선택 속성을 공유합니다. 속성 파일을 중복 게시하지 않으며, 카탈로그 검증기는 파티션별 건물 수 합계와 원래 건물 수를 대조합니다. 선택 요청에서도 ID가 해당 파티션 소속인지 검사합니다. 기존 카탈로그에는 이 선택 필드가 없으므로 기존 조회는 그대로 유지됩니다.

중단한 명령을 같은 출력 경로로 다시 실행하면 완료한 확대 수준을 재사용합니다. 후보 `publication.json`과 카탈로그는 새 데이터 릴리스에 연결해야 실제 서비스에 적용됩니다. 지역 범위는 여전히 확보된 서울·인천 상세 원본이며, 전국 건물 완전성이나 실제 기기의 성능 달성을 뜻하지 않습니다.
