# 부동산 비교 기능과 실제 연결 상태

2026-09-25. 대상은 아파트 우선, 오피스텔은 검증된 별도 원천 연결 이후다. 기존 3D 구현·자료는 변경하지 않는다.

## 이번 구현

- 목록: 선택 월 최근 계약의 전용 평당가, 전용 평당가 오름·내림차순, 국평 면적 필터.
- 상세: 전용 평당가 중앙값, 국평 84㎡대 실제 계약 중앙값·표본 수. 기간 중 수집 확인된 월만 사용한다.
- 차트: 총액 / 전용 평당가 / 전용 ㎡당가 전환. 점·선택 기록·축 단위가 함께 바뀐다. 계약표·CSV 원금액은 유지한다.
- 비교: 같은 계약월·면적의 신고가격 중앙값과 전용 평당가. 84㎡대 조건을 공유 주소에서도 복원한다.
- 출퇴근: 기기에 목적지 최대 3개 저장·삭제, 선택 단지 주소부터 같은 직장·학교까지 대중교통·자동차·도보 외부 경로 연결. 자체 ETA, 환승 경로, 등시간 지도는 아직 없다.

### 계산 계약

전용 평당가 = 개별 신고금액 / 전용면적(㎡) × 400/121. 원천에 공급면적이 없으므로 공급 평당가로 부르지 않는다. 단지 중앙값은 개별 평당가의 중앙값이며, 금액 중앙값을 면적 중앙값으로 나눈 값이 아니다.

국평은 제품의 명시적 필터인 `84 ≤ 전용면적 < 85㎡`다. 법률상 국민주택 규모나 모든 시장의 33·34평형과 동일하다는 주장이 아니다. 59㎡ 가격을 84㎡로 비례 환산하지 않는다. 84㎡대 계약이 없으면 값을 제공하지 않는다.

전월세는 보증금 기준 단가이며 월세를 합치거나 가상의 매매가로 환산하지 않는다. 월세가 다른 계약의 보증금 분포가 섞일 수 있음을 명시한다. 매매·임대차의 확실한 단지/면적 연결 전에는 전세가율·매매전세갭을 생성하지 않는다. 취소·검토·취소 상태 미확인 매매는 요약에서 제외한다. 공유·원문 표·비교도 같은 면적 조건을 적용한다.

### 출퇴근

Google Maps의 공식 [Maps URLs](https://developers.google.com/maps/documentation/urls/get-started) 규격으로 생성한다. 원천 주소와 단지명을 검색 문자열로 전달하며, 지역 중심점이나 검증되지 않은 단지 점을 출발 좌표로 사용하지 않는다. 외부 지도에서 출발지 해석과 지원 교통수단을 확인해야 한다. 목적지는 localStorage의 버전 1 구조로만 저장하고 길이·최대 개수를 검증한다. 외부 링크를 누를 때만 목적지를 해당 지도에 전달한다. 목적지는 서버·공유 링크로 보내지 않는다.

## 유사 서비스 기능 대조와 남은 연결

[아실 공개 화면](https://asil.kr/asil/index.jsp)에서 가격·평당가·매매전세갭·전세가율·거래회전율·공급·인구·학군·교통망 메뉴를 확인했다. 호갱노노의 공개 상세와 검색 흐름은 이전 지도 UX 관찰 문서와 함께 참고했다. 이번 웹 조회의 호갱노노 응답은 403이었으며, 모든 화면·로그인 기능을 열람했다고 표현하지 않는다.

| 기능군 | 현재 상태 | 다음 구현에 필요한 조건 |
|---|---|---|
| 실거래·전용 단가·84㎡대·면적 비교 | 구현 | 공급면적과 동일 세대형의 공식 연결 후 공급 평당가 추가 |
| 관심 단지·지역 검색·최대 3단지 비교 | 기존 제공, 단가 비교 보강 | 저장 조건·가격 변동 알림의 서버 운영 |
| 출퇴근 목적지 | 기기 저장·외부 경로 제공 | 무료 제공조건이 확인된 경로/대중교통 데이터, 검증 좌표, 출발 시각, 환승·도보 구간 |
| 전세가율·매매전세갭 | 미제공 | 같은 단지·면적·기간의 확실한 임대차 식별, 순수전세 분리, 표본 표시 |
| 거래회전율 | 미제공 | 기간별 거래와 같은 기준일의 총 세대수 |
| 공급·미분양·입주예정 | 미연결 | 공식 시계열, 계획/승인/착공/준공 상태와 변경 이력 |
| 인구·가구·전입/전출 | 미연결 | KOSIS 원천과 행정개편 대응 |
| 학군·통학·주변 시설 | 미연결 | 공식 통학구역·기준일, 시설 좌표, 실제 보행 경로 |
| 주차·관리비·용적률·건폐율 | 미연결 | K-apt/건축물 대장 단지 연결과 단위·시점 검증 |
| 민간 매물·호가·거리뷰·독점 시세 | 제공 안 함 | 제공 권한과 비용 조건. 화면을 참고한 사실을 데이터 이용권으로 간주하지 않음 |

위 미연결 기능을 완료로 처리하지 않는다. 기능 대조표는 공개 화면에서 확인한 범위의 개발 장부이며 모든 유사 서비스 기능에 대한 완전한 조사 결과는 아니다.
