# 서울·인천 상세 지도

2026-09-24. 전국 기본 지도를 유지하면서 사용자 지정 첫 수집 순위인 서울·인천의 원본 건물 윤곽과 상세 도로를 추가하는 배치입니다. 새 후보의 HTTP·브라우저·성능 검증 및 대표 주소 승격은 각각 별도로 판정합니다.

## 원본과 범위

- 범위는 SGIS 2025-06-30 **통계 행정경계**입니다. 서울 `11`, 인천 `23`은 SGIS 코드이며 공공데이터포털 법정지역 코드와 혼용하지 않습니다. 섬과 경계 구멍을 유지합니다.
- 기존 감사된 전국 건물 원본과 OSM 상세 기반 시설 원본을 사용합니다. 중간 카탈로그·건물 셀 목록의 해시 및 각 파일의 원본 SHA와 피처 수를 확인합니다.
- 자산 bbox는 후보 선별에만 사용합니다. 피처는 실제 경계 폴리곤과 교차해야 포함됩니다. 건물은 경계에 걸쳐도 원형을 보존하고, 도로는 표시 형상만 지역 경계로 잘라냅니다.
- 건물 ID, 원본 형상 해시, 원천 속성과 높이 품질을 선택 자료에 보존합니다. 추정 높이를 실측으로 바꾸지 않으며, 공식 단지 좌표를 만들어내지 않습니다.
- 범위 내 원본 선별 결과는 건물 **468,104개**, 도로 형상 조각 **216,257개**입니다. 같은 도로 ID의 서로 다른 형상 조각은 구분합니다. 이는 실제 모든 건물·도로의 완전성이나 최신성을 입증하는 수치가 아닙니다.

## 표시와 처리

`pipeline/map_tiles_regional.py`는 원본별 SQLite 체크포인트를 만들고, 실패한 원본 트랜잭션을 되돌립니다. 준비된 경계의 포함 검사를 먼저 수행해 경계 안의 도로에 불필요한 교차 연산을 하지 않습니다. 경계를 통과한 도로만 잘라냅니다.

건물과 상세 도로는 줌 14의 MVT로 생성합니다. 단일 디코딩 타일·PMTiles 묶음의 1MiB 상한을 유지하며 초과 시 실패합니다. 건물을 삭제해서 크기를 맞추지 않습니다. 8192 정수 격자로 면을 표현할 수 없으면 명시적 외곽선 또는 점으로 남깁니다. 클라이언트는 외곽선·면·점 모두 표시합니다. 더 확대하면 표시 격자의 오차가 커지며 측량 정확도와 다릅니다.

전국 기존 6개 주제는 바이트 단위로 재사용합니다. `buildings`, `detail-roads`를 추가하고 국토 전체의 기존 도로를 보존합니다. 상세 도로는 기존 개략 도로 위의 별도 레이어이며, 서로 다른 상세도가 겹칠 수 있습니다. 출처 목록에 Overture와 European Union/JRC를 포함합니다. [Overture의 테마·원천별 이용조건](https://docs.overturemaps.org/attribution/)은 코드의 MIT 라이선스와 별개입니다.

화면 하단은 전국 기본 지도와 서울·인천 상세 범위를 구분합니다. 단지 실거래 ID 연결, 아파트 위치 검증, 이력 수집 범위는 이 건물 윤곽 레이어와 별개의 상태입니다.

## 실행

```powershell
.venv/Scripts/python.exe -B -m pipeline.map_tiles_regional --baseline .local/map-tiles-20260920/mobile-overview-candidate --output .local/regional-detail-20260924/candidate
```

같은 출력 경로는 동일한 코드·원천·경계 입력일 때만 재개합니다. 입력이 바뀌면 새 출력 경로를 사용합니다. 원본이나 이전 후보는 삭제하지 않습니다. 최초 v1 생성물의 출처 목록만 보강하는 `--reuse-index`는 승인된 정확한 변환 해시, 원천 목록, 경계, 높이·타일 변환 해시가 일치한 완전한 색인만 읽기 전용으로 재사용합니다. 기존 형상과 타일 바이트를 변경하지 않습니다.

## 검증 경계

회귀 검사는 섬·구멍·경계 교차, 모든 최대 줌 ID의 표현, 원본 해시 변경, 충돌 ID 롤백, 체크포인트 재개, 기존 전국 주제 보존, 상세 도로 스타일과 지역 범위 표시를 다룹니다. 원본 데이터의 현실 정확성, 전국 10년 실거래 수집, 자동 수집 활성화와 10배 성능 향상은 이 검사로 증명하지 않습니다.

공개 후보 URL, 실제 타일 크기·ID 감사 결과와 브라우저 검수 기록은 생성·배포가 끝난 뒤 추가합니다.
