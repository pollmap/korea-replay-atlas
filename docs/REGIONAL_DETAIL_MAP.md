# 서울·인천 상세 지도

2026-09-24. 전국 기본 지도를 유지하면서 사용자 지정 첫 수집 순위인 서울·인천의 원본 건물 윤곽과 상세 도로를 추가하는 배치입니다. 새 후보의 HTTP·브라우저·성능 검증 및 대표 주소 승격은 각각 별도로 판정합니다.

## 원본과 범위

- 범위는 SGIS 2025-06-30 **통계 행정경계**입니다. 서울 `11`, 인천 `23`은 SGIS 코드이며 공공데이터포털 법정지역 코드와 혼용하지 않습니다. 섬과 경계 구멍을 유지합니다.
- 기존 감사된 전국 건물 원본과 OSM 상세 기반 시설 원본을 사용합니다. 중간 카탈로그·건물 셀 목록의 해시 및 각 파일의 원본 SHA와 피처 수를 확인합니다.
- 자산 bbox는 후보 선별에만 사용합니다. 피처는 실제 경계 폴리곤과 교차해야 포함됩니다. 건물은 경계에 걸쳐도 원형을 보존하고, 도로는 표시 형상만 지역 경계로 잘라냅니다.
- 건물 ID, 원본 형상 해시, 원천 속성과 높이 품질을 선택 자료에 보존합니다. 추정 높이를 실측으로 바꾸지 않으며, 공식 단지 좌표를 만들어내지 않습니다.
- 범위 내 원본 선별 결과는 건물 **468,104개**, 도로 형상 조각 **216,257개**입니다. 같은 도로 ID의 서로 다른 형상 조각은 구분합니다. 이는 실제 모든 건물·도로의 완전성이나 최신성을 입증하는 수치가 아닙니다.

## 표시와 처리

`pipeline/map_tiles_regional.py`는 원본별 SQLite 체크포인트를 만들고, 실패한 원본 트랜잭션을 되돌립니다. 준비된 경계의 포함 검사를 먼저 수행해 경계 안의 도로에 불필요한 교차 연산을 하지 않습니다. 경계를 통과한 도로만 잘라냅니다.

건물과 상세 도로는 줌 14의 MVT로 생성합니다. 단일 디코딩 타일·PMTiles 묶음의 1MiB 상한을 유지하며 초과 시 실패합니다. 건물을 삭제해서 크기를 맞추지 않습니다. 8192 정수 격자로 면을 표현할 수 없으면 명시적 외곽선 또는 점으로 남깁니다. 클라이언트는 외곽선·면·점 모두 표시합니다. 더 확대하면 표시 격자의 오차가 커지며 측량 정확도와 다릅니다.

전국 기존 6개 주제는 바이트 단위로 재사용합니다. `buildings`, `detail-roads`를 추가하고 국토 전체의 기존 도로를 보존합니다. 상세 도로는 기존 개략 도로 위의 별도 레이어이며, 서로 다른 상세도가 겹칠 수 있습니다. 출처 목록에 Overture와 European Union/JRC를 포함합니다. [Overture의 테마·원천별 이용조건](https://docs.overturemaps.org/attribution/)은 코드의 MIT 라이선스와 별개입니다.

화면 하단은 전국 기본 지도와 서울·인천 상세 범위를 구분합니다. 단지 실거래 ID 연결, 아파트 위치 검증, 이력 수집 범위는 이 건물 윤곽 레이어와 별개의 상태입니다.

## 실행

```powershell
.venv/Scripts/python.exe -B -m pipeline.map_tiles_regional --baseline .local/map-tiles-20260920/mobile-overview-candidate --output .local/regional-detail-20260924/candidate
```

같은 출력 경로는 동일한 코드·원천·경계 입력일 때만 재개합니다. 입력이 바뀌면 새 출력 경로를 사용합니다. 원본이나 이전 후보는 삭제하지 않습니다. `--reuse-index`는 승인된 정확한 v1 변환 해시, 원천 목록, 경계와 높이 변환이 일치한 완전한 색인만 읽기 전용으로 재사용합니다. 타일 변환이 같으면 타일도 재사용합니다. 승인된 최초 타일 변환에서 현재 변환으로 바뀌면 원본 색인만 복사하고 타일과 해당 완료 상태는 모두 다시 생성합니다.

실제 첫 도로 타일 검사에서 355개 ID 누락을 검출해 게시를 중단했습니다. 투영 후 두 끝점이 같은 부동소수점 값이 되거나 매우 짧아진 도로 조각이 교차 연산에서 빈 형상으로 바뀌는 사례를 확인했습니다. 표시 격자의 1/100 이하 길이 조각은 교차 연산 전에 명시적 점으로 표현하며 원본 형상과 ID는 보존합니다. 이 변경은 `subpixel_line_anchor`로 기록합니다. 새 타일의 전체 ID 검증을 다시 통과하기 전에는 후보를 게시하지 않습니다.

## 검증 경계

회귀 검사는 섬·구멍·경계 교차, 모든 최대 줌 ID의 표현, 원본 해시 변경, 충돌 ID 롤백, 체크포인트 재개, 기존 전국 주제 보존, 상세 도로 스타일과 지역 범위 표시를 다룹니다. 원본 데이터의 현실 정확성, 전국 10년 실거래 수집, 자동 수집 활성화와 10배 성능 향상은 이 검사로 증명하지 않습니다.

### 실제 생성과 데이터 배포 결과

최종 지도 릴리스는 `map2d-bb9f72fdf7b812cc3c79`입니다. 건물 468,104개와 도로 조각 216,257개의 모든 원본 ID가 최대 줌 타일에 표현됐음을 검사했습니다. 첫 후보의 355개 누락을 수정한 뒤 전체 타일을 다시 생성했으며, 미세 도로 조각 375건의 별도 검사에서도 누락이 없었습니다. 이는 확보한 원본의 타일 표현 검사이며 현실 세계의 모든 건물을 확보했다는 뜻은 아닙니다.

| 항목 | 건물 | 상세 도로 |
|---|---:|---:|
| 줌 14 타일 | 597개 | 716개 |
| 최대 압축 타일 크기 | 230,726 B | 74,209 B |
| PMTiles 묶음 | 30개 | 16개 |
| 선택 속성 파일 | 335개 | 69개 |

기존 전국 자료를 포함한 새 지도 게시물은 719파일·215,732,713 B입니다. 기존 부동산 게시물과 합친 데이터 배포는 4,882파일·2,096,964,637 B이며, 새 자산 452개 업로드와 기존 자산 4,429개 재사용이 확인됐습니다.

실제 [데이터 배포 manifest](https://564c765e.korea-replay-data.pages.dev/data/atlas/atlas-5325d21fbda8cc94/manifest.json)의 SHA-256은 `4703154a8b053a36b9b26d1cccd72729ea4b71250269bfa4c5577b82dc7c0f80`입니다. 원격 manifest·지도 카탈로그·부동산 manifest의 해시, 서울시청·인천 구월동의 건물/도로 타일 네 개의 해시 및 PMTiles 판독, CORS, 불변 캐시, 누락 자료 404를 확인했습니다. 원격 전체 파일 재다운로드 검사나 대표 주소 승격을 뜻하지 않습니다.

로컬 브라우저에서는 서울 단지 주변과 인천 동네의 건물 윤곽·도로를 표시하고 도로 선택의 원본 ID 조회를 확인했습니다. 당시 다른 배치가 실행 중이었으며 첫 지도 준비 10,738.9ms, 이동 표본 139개의 P95 64.1ms를 관찰했습니다. 통제된 비교 실험이 아니고 성능 목표도 통과하지 않았습니다. 공개 앱 후보의 브라우저 검증과 대표 주소 승격은 별도로 진행합니다.

[상세 지도 앱 후보](https://df390001.korea-replay.pages.dev/)가 배포됐습니다. artifact는 `09a51360d1c6144830a27e2c14e942b29910d51a02fa31e8725a32ec3950d707`이며, runtime의 앱·데이터 고정 참조와 JS/CSS·index·catalog·단지 위치 색인 등 14개 응답을 업로드 manifest와 대조했습니다. 서울시청 주변 상세 화면에서 오류 0, 첫 준비 2,792.1ms를 관찰했습니다. 1회 비통제 측정이므로 성능 인수나 개선 배율의 근거로 사용하지 않습니다. 대표 주소는 승격하지 않았습니다.

이 배포 이후 [아파트 중심 제품 범위](PRODUCT_SCOPE.md)로 우선순위를 고정했습니다. 이 문서의 일반 건물·도로 작업은 이미 만든 지도 배경의 기록이며, 같은 종류의 정밀 보강을 계속 추진하는 로드맵이 아닙니다. 아파트 탐색의 배경 객체 선택 제한은 위 후보 이후 소스 변경이므로 이 후보에 적용됐다고 취급하지 않습니다.
