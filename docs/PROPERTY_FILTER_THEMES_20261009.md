# 조건 묶음과 지도·목록 일치 — 2026-10-09

## 구현

기존 `내 검색조건` 안에서 다음 두 묶음을 제공합니다. 별도 추천 패널·점수·새 데이터는 만들지 않습니다.

| 묶음 | 실제 적용 조건 | 유지하는 조건 |
|---|---|---|
| 국평 · 낮은 가격순 | 전용 84㎡ 이상 85㎡ 미만, 최근 거래금액 낮은순 | 예산·법정동·검색·건축연도·선택 기간·거래 유형 |
| 국평 · 최근 10년 건축 | 전용 84㎡ 이상 85㎡ 미만, 선택 계약월의 연도 − 10년부터 해당 연도까지 | 예산·법정동·검색·정렬·선택 기간·거래 유형 |

예를 들어 기준 계약월이 2026.09이면 건축연도 2016–2026을 적용합니다. 오늘 날짜가 바뀌어도 공유한 조건의 값은 변하지 않습니다. 건축연도는 기존 실거래 신고 원문 값이며 입주·준공일을 새로 확정하지 않습니다.

조건을 적용하면 실제 면적·건축연도 칩과 정렬 선택에 표시되고, 기존 입력과 칩으로 수정·해제할 수 있습니다. 테마 ID를 공유하지 않고 기존 `PropertyViewState`의 구체적인 조건을 저장합니다. 같은 법정동을 유지할 때는 지역 변경 콜백을 다시 실행하지 않아 선택한 단지를 해제하지 않습니다.

세대수·주차·역 거리·종합 점수·예측은 이번 테마에 포함하지 않습니다. 최신 가격은 선택 기간·면적의 마지막 유효 실거래 기준이며 매물 호가가 아닙니다. 월세의 금액 정렬은 기존 보증금 기준을 유지합니다.

## 함께 수정한 불일치

- 목록과 지도가 동일한 완료/실제 0건/원천 미제공/미확인 월 판정을 공유합니다.
- 실패하거나 미확인인 월의 요약행으로 지도 가격을 바꾸지 않습니다.
- 선택 면적·전월세 유형의 거래가 없는 단지는 확인이 끝난 기간에만 조건 밖으로 처리합니다.
- 미확인 기간의 가격 미확인 단지는 목록과 지도에서 같은 방식으로 유지합니다. 가격이나 거래 0건을 만들어 내지 않습니다.
- 지도에 표시할 수 있는 단지 위치의 범위는 그대로입니다. 목록에 있는 모든 단지의 위치 확보를 의미하지 않습니다.

## 검증과 남은 게이트

관련 단위·회귀 검사 90개: 조건 유지, 공유 복원, 개별 해제, 건축연도 미제공, 실패 월 가격, 원천 제공 전 기간, 면적·예산별 지도/목록 후보 일치를 검사했습니다. TypeScript와 ESLint 검사를 통과했습니다.

실제 PC 브라우저에서 `지역 목록 → 내 검색조건 → 조건 묶음 → 개별 수정/해제 → 공유/뒤로가기`와 지도 표식의 후보 일치를 확인한 뒤 공개합니다. 이 문서의 작성 시점에는 해당 변경의 실제 브라우저 검수와 공개 배포는 완료하지 않았습니다.
