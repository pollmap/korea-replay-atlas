## PC 화면 변경

- 2D 아파트 탐색의 작업명을 맛동산으로 분리하고 자체 건물 벡터 심볼을 사용합니다. 남색·주황색 토큰과 흰색 바탕을 적용합니다. 이름의 상표 사용 가능성을 확인한 것은 아닙니다.
- 상단에서 전국 지역과 현재 선택 지역의 단지를 검색합니다. 아직 전국 단지·주소·역 통합 색인 검색은 아닙니다. 검색 범위를 입력창과 결과에 명시합니다.
- 관심·비교 진입, 단지 선택 강조, 이전 목록 보존을 연결합니다. 노트북은 380px 패널, 1600px 이상은 280px 목록과 420px 상세를 함께 보여줍니다.
- 차트와 주요 보조 글자를 키우고 확대창을 제공합니다. 확대창을 닫으면 버튼으로 초점이 돌아오고, 월별 점을 선택하면 원문 거래표로 이동합니다.
- 월별 마지막 유효 계약의 의미를 유지해 ‘월별 최근 거래’로 표시합니다. 월 중앙값이나 전체 거래 분포로 바꾸지 않습니다.
- 조건 집계 미연결 표식은 ‘조건별 집계 전’으로 표시합니다. 가격·기간이 다른 값으로 조용히 대체하지 않습니다.
- 기존 3D 렌더러·자료는 변경하지 않습니다. 공통 App의 브랜드 변경은 2D 탐색에서만 적용하고 기존 스타일은 3D에서 유지합니다.
