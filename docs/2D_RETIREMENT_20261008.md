# 2D 전용 전환 — 검증 기록

## 구현

- 앱의 3D·햇빛·재생·현재 관측 진입과 전용 렌더러를 제거했습니다.
- Cesium과 전용 정적 복사 플러그인을 제거했습니다. 지도 핸들은 MapScene에서 중립 타입으로 분리했습니다.
- 2D 지도에 남아 있던 버스 소스·5초 타이머를 제거했습니다.
- 이전 3D 링크는 짧은 종료 안내를 보이며 2D로 엽니다. 배포/자료 버전 검증은 유지합니다.
- 지도·단지·관심·비교·기존 아파트 공유 흐름을 유지하는 후보입니다.
- 3D 생성 CLI 명령을 종료 처리했습니다. 2D 외곽선/도로/수역 입력과 과거 Git 이력은 보존합니다.
- Pages의 명시적 `retire3d` 옵션은 Cesium 및 공간 파일과 과거 3D 리디렉션을 제외합니다. 기본 호환 검증 경로는 유지합니다.
- 같은 산출물을 다시 생성하면 완성된 기존 stage를 전수 검증한 후 재사용합니다. 미완성·변조 stage는 재사용하지 않습니다.

## 검증과 아직 닫히지 않은 조건

타입·린트·프로덕션 빌드를 통과했습니다. 새 빌드에는 Cesium/MapScene 청크가 없습니다. 2D 데이터와 거래 릴리스 포인터는 변경하지 않았습니다. 원문/금액/좌표를 수정하지 않았습니다.

PC 브라우저 검증은 Windows 도구가 현재 URL을 확인하지 못하여 중단됐습니다. 최신 공개 앱 8141b2557876a15e에는 아직 Git main에 없는 로컬 연구 화면과 지도 개선이 있으므로 이 후보를 그대로 대표 주소에 승격하면 안 됩니다. 원래 로컬 체크아웃을 수정하거나 덮어쓰지 않았습니다. 최신 변경과 통합한 별도 후보의 실제 PC 검증 후 병합·배포해야 합니다.

공개 배포·전체 2D 전환 완료를 선언하지 않습니다. raw XML 작업본의 압축 저장소 전환, 자동 후보 TTL 운영 연결, 위치/기본정보 보강, 테마·관계 UI, 전체 PC 재설계는 아직 남아 있습니다.
