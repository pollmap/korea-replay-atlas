## 저장 공간과 20년 목표의 차이

이번 원격 재감사에서 객체 shard 4개 사용량은 **652,156,928B**, 내부 상한 합계는 **1,593,835,520B (4×380MiB)**, 합계 잔여는 **941,678,592B**였습니다. 가장 작은 단일 shard 잔여는 214,908,928B였습니다. 100회/64MiB 원본 최악 비용 사전검사는 shard마다 90,258,004B를 요구하며 당시 통과했습니다. 이는 원본 payload 한 회분의 검사로, 장기 완료나 파생물까지 보장하지 않습니다.

실제로 분해한 기존 100호출/86완료 실행을 기준으로 아래 시나리오를 계산했습니다. 신규 base64 raw payload 2,808,656B와 gzip snapshot payload 8,832,732B는 데이터량에 비례하는 항목으로 구분했습니다. 체크포인트·manifest·기타 SQLite 증가 3,464,660B는 별도로 둡니다. 모든 작업을 175KB로 단순 환산하지 않았습니다.
