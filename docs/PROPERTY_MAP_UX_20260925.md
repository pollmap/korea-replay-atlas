# 2D 지도 표식과 탐색 위계 수정

2026-09-25. 기존 3D 소스와 자료는 변경하지 않는다.

## 확인한 문제

지역 거래량 카드는 줌 10에서 사라지고, 서울 아파트 제공 점의 군집 원이 나타났다. 원의 숫자는 거래 건수가 아닌 단지 개수였다. 이름이 사라지고 지표의 의미까지 바뀌어 확대 전후 정보를 비교하기 어려웠다.

## 참고 화면에서 확인한 구성

| 서비스 | 직접 확인한 화면 | 적용한 흐름 |
|---|---|---|
| [호갱노노](https://hogangnono.com/) | 지도 첫 화면, 헬리오시티 검색 결과, 단지 상세 | 왼쪽 검색과 상세, 단지명과 거래 조건을 먼저 제시, 지도 가장자리 조작, 이름이 있는 단지 표식 |
| [아실](https://asil.kr/asil/index.jsp) | 데스크톱 전국 지도와 좌측 검색·지역 선택, 상단 필터 | 시도→시군구 선택, 이름과 수치를 함께 담은 사각형 지역 카드, 지도와 목록의 고정된 위치 |

이번 확인은 위 화면에 한정한다. 로그인 영역·모든 메뉴·모든 모바일 화면을 검토했다는 의미가 아니다. 자체 브랜드와 공개 가능한 데이터는 유지하며, 두 서비스의 비공개 자료와 독점 지도를 가져오지 않았다.

## 구현

- 시도·시군구·단지는 같은 사각형 스프라이트를 사용한다. 지역 이름은 13~14px 기준이며 확대 후에도 지역 거래량 카드가 사라지는 상한을 없앴다.
- 이름 없는 아파트 군집 원과 숫자만 있는 단지 묶음을 제거했다. 줌 13부터 단지명 카드가 보이며, 선택한 단지는 줌 10부터 유지한다. 겹치는 일반 표식은 충돌 배치로 조절한다.
- 단지 카드에는 해당 릴리스에서 연결된 최근 매매와 계약일을 표시한다. 전월세 선택 시 매매가를 전월세로 표시하지 않는다. 미연결 단지는 공식 단지 정보라고 표시한다.
- 동별 거래 통계가 없는 곳에 구 거래량이나 단지 개수를 동 거래량으로 붙이지 않는다. 원래 행정동 라벨과 거래 지역의 법정 코드 체계를 구분한다.
- 2D 탐색의 데스크톱 검색을 왼쪽 패널 맨 위로 이동했다. 시도·시군구 선택 → 지역/단지 → 거래 조건 → 차트/목록 순서를 유지한다. 모바일은 기존 하단 패널을 유지한다.
- 관심 저장·비교·좌표 검토 표시와 기존 데이터의 출처는 유지한다.

## 검사 범위

MapLibre 스타일 유효성, 확대 시 지역 레이어 유지, 단지명 보존, 릴리스·매매/전월세가 다른 가격의 표시 차단을 회귀 검사한다. 브라우저에서는 전국→서울→송파구→단지 카드→실거래 상세, 모바일 하단 패널, 지도 집중 전환을 확인한다.

동별 실거래 집계와 전국 단지 좌표가 추가로 확보됐다는 뜻은 아니다. 이번 변경은 기존 검증 자료의 표시 방식과 탐색 구조에 한정한다.
