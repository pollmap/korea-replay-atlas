## 완료 판정 규칙

- **구현 확인**: 해당 조건과 실패 경로를 코드·회귀 테스트로 확인했다. 실제 자료와 공개 브라우저 검증을 대신하지 않는다.
- **부분 제공**: 공개에서 일부 사용할 수 있지만 범위·자료·조작 중 미충족 조건이 있다.
- **연결 대기**: 원천·권리·식별자·실제 연동이 준비되지 않았다. 최신 사용자 지시에 따라 화면·탭·필터·빈 상태는 먼저 제공한다. 없는 수치와 장소, 소요시간을 채우지 않으며 실제 조회 중이 아닐 때 로딩으로 표시하지 않는다.
- **검증 대기**: 구현이 있어도 아래 조건의 실제 결과가 없다.
- **완료**: 실제 공개 릴리스 ID, 대상 지역/월/면적, 브라우저 크기, 검사 결과와 날짜가 기록돼 있고 해당 조건에 미해결 실패가 없다. 완료 후에도 변경된 코드·자료는 다시 검사한다.

전체 제품 완료는 필수 항목의 평균 점수로 판정하지 않는다. 사용자가 요구한 기능에 미구현·자료 결손·권리 미확정이 남으면 그대로 남긴다. 광고·중개사 영업·타사 후기와 독점 시세 복제는 기본 사용 흐름의 완료 조건으로 넣지 않으며, 희망 기능 자체와 재사용 권리는 별개다.

## 20년 원천 계약과 확보 장부

2026년 9월 기준 완료월은 **2006.09–2026.08**이며 **2026.09는 잠정**이다. 최신 월이 바뀌면 같은 규칙으로 이동한다. 국토부 공개체계는 매매 2006.01부터, 전월세 확정일자 자료 2011.01부터다. 따라서 이 20년 창의 전월세에는 원천 제공 전 52개월이 있다. 매매 20년과 전월세 제공 가능한 전 기간을 구분하고, 20년 전월세 원문이 존재한다고 주장하지 않는다. [공식 원천 안내](https://rt.molit.go.kr/pt/info/info.do?mobileAt=), [권리·원천 감사](PROPERTY_SOURCE_RIGHTS_20260927.md).

최신 9개 권역은 공식 수집 목록의 **112개 지역 코드**다(경기47·서울25·인천11·천안2·아산1·세종1·청주4·대전5·부산16). 241개월의 아파트 매매/전월세 총 **53,984개 슬롯** 중 5,824개는 원천 제공 전이며 실제 수집 대상은 **48,160개**다. 전국 보존 장부는 복원 계약 유지를 위해 256개 코드·123,392슬롯을 유지하지만, 범위 밖 144개 지역에 새 API 요청은 보내지 않는다. 이것은 **계획 개수**이며 확보 완료나 과거 행정구역의 완전한 대응이 아니다. 과거 코드와 현행 코드의 관계가 검증되지 않으면 이름만으로 과거 거래를 현재 경계에 합치지 않는다.

장부에는 대상월, 원천 시작월, 미수집/수집 중/정상 완료/정상 빈 결과/실패/원천 제공 전, 페이지 수·건수·해시·수집시각·정정 확인을 남긴다. 기존 121개월 장부를 확장할 때 원본·완료 작업·체크포인트를 지우지 않는다. 현재 수집은 경기→서울→인천→천안→아산→세종→청주→대전→부산 안에서 진행하며 다른 지역은 새로 요청하지 않는다.

브라우저는 긴 기간을 선택해도 다운로드·요청·보관 거래량 상한을 둔다. 상한에 걸린 월의 일부만 정상 통계로 제공하지 않는다. 미확인 구간을 명시하고, 기간을 나눠 확인할 수 있게 한다. 차트의 시각 요약과 원문 표/CSV 범위도 구분한다.

## 이번 구현과 실제 화면 검증

20년 조회를 상세·비교·공유 URL에 연결하고 기존 10년 링크를 유지했다. 출처 식별자·공식 문서가 일치하는 경우에만 원천 시작월을 적용한다. 한 번의 이력 조회는 24MiB·512파일·20,000거래로 제한하고, 상한에 걸린 월의 일부만 정상 통계로 집계하지 않는다. 비교는 이 예산을 지역별로 나눈다.

기존 차트는 최근 1,000건만 잘라서 오래된 거래가 화면에서 사라졌다. 이제 1,000건 이하는 전부 표시하고, 초과하면 각 월의 최저·최고·중앙순위·최신 **실제 거래**를 사용한다. 240개월에서 최대 960점이며 표에서 선택한 거래까지 최대 961점이다. 가격축은 확인된 전체 거래로 계산하고 표·CSV의 원본 범위는 유지한다. 대표점은 거래량이나 평균값을 만들어 낸 거래가 아니다.

장기 이력에서 오래된 차트 거래를 선택할 때 선행 기록 전체를 DOM으로 만들던 경로도 수정했다. 거래표는 처음 12행, 확장 후 최대 48행씩 표시하며 선택 거래가 있는 페이지로 바로 이동한다. 이전/다음 페이지로 확인한 전체 거래에 접근하고 CSV는 전체 범위를 유지한다. 필터·조회 범위 변경 시 첫 페이지로 복귀한다. 2만 건의 마지막 기록 이동과 모든 페이지의 누락·중복을 회귀 검사한다. 주변 탭의 2D 전용 상태가 다른 지도 모드에서 빈 본문으로 이어지지 않도록 공유 패널의 유효 탭을 계산한다.
