## 화면에서 배울 점과 검증할 흐름

두 1280px 데스크톱 화면은 왼쪽 패널이 약 375~390px이고 나머지 약 70%를 지도에 사용합니다. 아실은 지역 지표·분석 도구를 지도 가장자리에 두고, 호갱노노는 단지 선택 후에도 같은 지도에서 주변 건물과 가격을 계속 볼 수 있습니다. **목록/상세/필터를 여러 겹 쌓지 않고 한 패널에서 전환하는 구조**를 채택합니다. 파랑·보라 브랜드를 복제하는 것이 개선 완료 조건은 아닙니다.

1. 전국 지도에서 지역 또는 단지를 검색하고 결과를 선택합니다. 단지의 검증된 좌표가 없으면 확정 위치처럼 이동하지 않습니다.
2. 단지를 선택하면 지도·목록의 선택을 유지하고 주소·식별 근거·면적·기간·거래 유형을 보여줍니다.
3. 같은 면적의 실제 계약 점을 누르면 날짜·층·금액·취소 여부를 읽고 원문 표와 같은 값임을 확인합니다. 미확인 기간은 빈 음영/상태로 보이며 0건과 구분됩니다.
4. 최대 3개 단지를 같은 기간·면적으로 비교하고, 조건을 바꾸거나 뒤로 가도 위치·필터가 유지됩니다.
5. 모바일에서 패널을 접어 지도를 탐색한 뒤 다시 열며, 키보드로 검색→결과→상세→닫기 후 초점 복귀를 확인합니다.

스크린샷만으로 경쟁 앱의 처리 속도·스크린리더·터치 목표 크기·키보드 동작·차트 계산 정확성을 검증할 수 없습니다. 우리 앱은 같은 조건의 첫 지도/단지 선택/기간 변경/재방문 시간을 따로 측정하고, 메인 스레드에 전국 원본을 한꺼번에 올리지 않습니다. 모바일 조작 영역 44px, 가려진 초점·패널 겹침, 이동 중 불필요한 다시 그리기 여부를 실제 화면에서 확인합니다.

**다음 공개 판정:** 검증 좌표를 가진 실제 단지의 지도→상세→같은 면적 거래→비교→공유 복원 흐름이 작동하는지 우선 평가합니다. 좌표가 0개인 동안 전체 부동산 지도 기능을 갖췄다고 보고하지 않습니다. 장기 이력·전국 범위·공식 지표·화면 성능·새 배포는 각각 별도 완료 항목으로 관리합니다.
