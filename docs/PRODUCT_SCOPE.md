# 아파트 중심 제품 범위

2026-09-24 최신 사용자 지시. 이 문서는 기존 전국 지도·도시 도구를 보존하면서 현재 제품과 다음 개발의 우선 범위를 정합니다.

## 핵심 사용 흐름

지역·아파트 검색 → 단지 선택 → 면적·기간·거래 유형별 실거래 확인 → 단지 비교 → 관심 단지 저장.

기본 화면, 데이터 수집, 식별자 연결, 차트, 검색 색인, 성능 측정과 출시 검수는 모두 이 아파트 흐름을 대상으로 합니다. 지역 거래량도 아파트 거래 통계임을 명시하고 다른 주택 유형과 혼합하지 않습니다. 10년 이력 확보 목표는 아파트 매매·전월세에 적용합니다. 실제 미확보 기간은 숨기거나 0건으로 바꾸지 않습니다.

## 지도와 보조 기능

- 아파트 탐색 모드에서는 단지·지역을 선택합니다. 배경의 도로·일반 건물 클릭이 아파트 패널을 대체하지 않도록 합니다.
- 출처로 확인된 아파트 정보만 아파트 선택으로 취급합니다. 건물 이름에 '아파트'가 있거나 OSM 태그가 있다는 이유로 실거래 단지와 연결하지 않습니다.
- 기존 지형·일반 건물·도로는 위치를 이해하는 지도 배경으로 보존합니다. 3D·교통·기상·햇빛은 보조 도시 도구로 유지합니다.
- 빌라·연립·다세대·단독주택의 추가 수집과 일반 건물·작은 도로의 정밀 보강은 현재 개발 우선순위에서 제외합니다. 다른 주택 유형으로의 확장은 새 지시 전까지 추진하지 않습니다.

## 확보와 검수

[지역별 우선순위](PROPERTY_ACQUISITION_PRIORITY.md)에 따라 서울·인천부터 진행합니다. 개발 완료는 건물·도로의 수가 아니라 아파트 탐색·실거래·비교의 실제 작동, 데이터 범위·연결 정확성, 응답 속도와 화면 검수로 판단합니다. 소스 반영, 로컬 실행, 공개 미리보기, 대표 주소 배포를 구분합니다.
