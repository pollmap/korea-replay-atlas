# 아파트·오피스텔 제품 범위

2026-09-25 최신 사용자 지시. 이 문서는 기존 전국 지도·도시 도구를 보존하면서 현재 제품과 다음 개발의 우선 범위를 정합니다.

## 핵심 사용 흐름

지역·아파트·오피스텔 검색 → 단지 선택 → 면적·기간·거래 유형별 실거래 확인 → 단지 비교 → 관심 단지 저장.

기본 화면, 데이터 수집, 식별자 연결, 차트, 검색 색인, 성능 측정과 출시 검수는 아파트 우선, 오피스텔 추가 순서로 이 흐름을 대상으로 합니다. 지역 거래량도 아파트 거래 통계임을 명시하고 다른 주택 유형과 혼합하지 않습니다. 10년 이력 확보 목표는 아파트 매매·전월세에 적용합니다. 실제 미확보 기간은 숨기거나 0건으로 바꾸지 않습니다.

## 지도와 보조 기능

- 아파트 탐색 모드에서는 단지·지역을 선택합니다. 배경의 도로·일반 건물 클릭이 아파트 패널을 대체하지 않도록 합니다.
- 출처로 확인된 아파트 정보만 아파트 선택으로 취급합니다. 건물 이름에 '아파트'가 있거나 OSM 태그가 있다는 이유로 실거래 단지와 연결하지 않습니다.
- 기존 지형·일반 건물·도로는 위치를 이해하는 지도 배경으로 보존합니다. 3D·교통·기상·햇빛은 보조 도시 도구로 유지합니다.
- 빌라·연립·다세대·단독주택의 추가 수집과 일반 건물·작은 도로의 정밀 보강은 현재 개발 우선순위에서 제외합니다. 오피스텔까지만 추가하며, 빌라·연립·다세대·단독주택·상가·토지 거래로 범위를 넓히지 않습니다.

## 확보와 검수

[지역별 우선순위](PROPERTY_ACQUISITION_PRIORITY.md)에 따라 서울·인천부터 진행합니다. 개발 완료는 건물·도로의 수가 아니라 아파트 탐색·실거래·비교의 실제 작동, 데이터 범위·연결 정확성, 응답 속도와 화면 검수로 판단합니다. 소스 반영, 로컬 실행, 공개 미리보기, 대표 주소 배포를 구분합니다.

## 오피스텔 연결 기준

- 국토교통부 매매(15126464)·전월세(15126475)의 별도 원천을 사용합니다. 두 API의 공식 페이지는 무료·이용허락범위 제한 없음으로 표시되어 있으며, 실제 승인·응답 성공·수집 완료는 각각 확인합니다.
- `pipeline.real_estate_fetch --property-type officetel`은 반드시 별도 `--root`에 수집합니다. 아파트 체크포인트의 재사용은 오류로 차단합니다. 기본값은 기존 `apartment`입니다.
- 오피스텔에는 아파트 `aptSeq`를 만들어 넣지 않습니다. 공식 명세에 단지 식별자가 없으므로 현재 `complex_id`, `source_complex_id`, 좌표는 미연결로 유지합니다. 같은 이름이나 복합건물이라는 이유로 아파트와 합치지 않습니다.
- 취소 거래, 동일 속성의 여러 거래, 보증금·월세 단위를 보존합니다. 두 유형은 원본·정규화·통계·검색·비교·공유 상태에서 구분해야 합니다.
- 현재 공개 화면은 아파트입니다. 오피스텔은 수집·정규화 경로를 구현한 단계이며, 단지 연결·유형별 공개 릴리스·화면 필터는 아직 연결하지 않았습니다. 기존 아파트 게시기는 오피스텔 장부를 거부합니다.
- 아파트 우선 흐름을 먼저 완성하고, 동일한 지역 우선순위로 오피스텔을 추가합니다. 자료가 없는 기능을 동작하는 메뉴처럼 노출하지 않습니다.

공식 출처: [매매](https://www.data.go.kr/data/15126464/openapi.do), [전월세](https://www.data.go.kr/data/15126475/openapi.do).

실제 연동 확인(2026-09-25 KST): 별도 오피스텔 장부에서 최대 2회 요청 예산으로 점검했으나 첫 요청이 `upstream_auth`로 중단됐습니다. 오피스텔 실제 거래 수집 성공은 아직 0건이며, Chrome 포털에서도 로그인 만료를 확인했습니다. 승인 확인과 실제 응답 재검증이 필요합니다.
