# 아파트 중심 제품 범위

2026-10-05 최신 실행 범위: 경기·서울·인천·천안·아산·세종·청주·대전·부산의 아파트 수집 완료분 공개와 PC 핵심 흐름을 우선한다. 오피스텔과 충남·충북 나머지 지역은 다음 단계이며 이번 신규 수집·연결 대상이 아니다. 3D·모바일 전용 개편·호스팅 이전·유료 기능도 제외한다. 기존 자료와 과거 공유는 보존한다. 아래 과거 오피스텔 확장 기록은 현재 실행 승인으로 해석하지 않는다.
2026-10-01 최신 사용자 지시 반영. 이 문서는 기존 전국 지도·도시 도구를 보존하면서 현재 제품과 다음 개발의 우선 범위를 정합니다. 기능별 완료 기준은 [경쟁 서비스 비교·인수 기준](PROPERTY_PARITY_ACCEPTANCE_20260927.md)을 따르며, 최신 공개 상태는 [PC 릴리스 검증 기록](PC_PROPERTY_RELEASE_20261001.md)에 구분합니다.

## 핵심 사용 흐름

**이번 개발·자료 확보 대상은 경기·서울·인천·천안·아산·세종·청주·대전·부산으로 한정합니다.** 최신 사용자 지시를 따라 나머지 지역의 신규 확장·수집은 보류합니다. 기존 원본·완료 작업·공개 자료는 삭제하지 않고, 자동 수집의 모든 실행 경로에도 같은 범위를 적용합니다. 전국 확보는 현재 출시 조건이 아닙니다.

지역·아파트·오피스텔 검색 → 단지 선택 → 면적·기간·거래 유형별 실거래 확인 → 단지 비교 → 관심 단지 저장.

기본 화면, 데이터 수집, 식별자 연결, 차트, 검색 색인, 성능 측정과 출시 검수는 아파트 우선, 오피스텔 추가 순서로 이 흐름을 대상으로 합니다. 지역 거래량도 아파트 거래 통계임을 명시하고 다른 주택 유형과 혼합하지 않습니다. 이력 목표는 **연속 20년: 최신 완료 계약월까지 240개월, 당월 잠정 별도**입니다. 아파트부터 진행하며 오피스텔은 별도 원천·장부로 취급합니다. 실제 미확보 기간은 숨기거나 0건으로 바꾸지 않습니다.

2026-10 현재 목표 완료월은 **2006-10~2026-09**, 2026-10은 잠정입니다. 기존 2006-09와 과거 공유는 보존합니다. PC·노트북 탐색을 우선하며 모바일 전용 개편은 후순위입니다. [PC 인수 기록](PC_PROPERTY_ACCEPTANCE_20261001.md)을 구현·자료·실제 조작·배포로 나누어 판정합니다. 현행 국토부 공개체계는 매매 2006-01부터, 전월세 확정일자 자료 2011-01부터입니다. 원천 제공 이전은 `source_unavailable`로 구분하고, 20년 전월세 전체를 확보했다고 표시하지 않습니다. 원천 제공 이후의 모든 지역·월·유형에 페이지 완료와 취소·정정 확인 근거가 있어야 이력 확보를 완료로 판정합니다. 기간 선택 기능, 수집 계획 생성, 실제 수집 완료는 각각 별도입니다. [공식 원천·이용조건](PROPERTY_SOURCE_RIGHTS_20260927.md).

## 지도와 보조 기능

상세 건물 배경과 성능 개선은 서울·인천·경기도·대전·세종·청주 및 충남·충북을 우선합니다. 아래 일반 건물 보강 보류 방침에 대한 2D 지도 배경의 예외이며, 아파트·오피스텔 중심 상품 범위와 3D 수정 금지는 유지합니다. **전체 10배 성능 향상은 2026-09-27 사용자 지시로 목표에서 제외합니다.** 첫 진입, 지도 정지 후 자료 표시, 검색 응답과 모바일 조작은 실제 시간·오류·메모리로 계속 검증합니다. 과거 배율 측정 기록은 역사적 증빙으로만 보존합니다.

- 아파트 탐색 모드에서는 단지·지역을 선택합니다. 배경의 도로·일반 건물 클릭이 아파트 패널을 대체하지 않도록 합니다.
- 출처로 확인된 아파트 정보만 아파트 선택으로 취급합니다. 건물 이름에 '아파트'가 있거나 OSM 태그가 있다는 이유로 실거래 단지와 연결하지 않습니다.
- 기존 지형·일반 건물·도로는 위치를 이해하는 지도 배경으로 보존합니다. 3D·교통·기상·햇빛은 보조 도시 도구로 유지합니다.
- 빌라·연립·다세대·단독주택의 추가 수집과 일반 건물·작은 도로의 정밀 보강은 현재 개발 우선순위에서 제외합니다. 오피스텔까지만 추가하며, 빌라·연립·다세대·단독주택·상가·토지 거래로 범위를 넓히지 않습니다.

## 확보와 검수

[지역별 우선순위](PROPERTY_ACQUISITION_PRIORITY.md)에 따라 지정한 경기·서울·인천·천안·아산·세종·청주·대전·부산 범위에서 진행합니다. 개발 완료는 건물·도로의 수가 아니라 아파트 탐색·실거래·비교의 실제 작동, 데이터 범위·연결 정확성, 응답 속도와 화면 검수로 판단합니다. 소스 반영, 로컬 실행, 공개 미리보기, 대표 주소 배포를 구분합니다.

데이터 확보를 기다리지 않고 **화면 구조와 실제 조작을 먼저 개발**합니다. 단지정보의 정보 위치, 주변의 교통·학교·생활시설·개발계획 분류, 거리·유형 필터와 정렬은 연결 전에도 제공합니다. 미연결 값은 `연결 전`, 확인된 원문 누락은 `원문 미제공`으로 구분하고, 가짜 수치·가짜 장소·끝없는 로딩을 넣지 않습니다. UI 완료와 실제 자료 연결 완료는 따로 판정합니다.

## 오피스텔 연결 기준

- 국토교통부 매매(15126464)·전월세(15126475)의 별도 원천을 사용합니다. 두 API의 공식 페이지는 무료·이용허락범위 제한 없음으로 표시되어 있으며, 실제 승인·응답 성공·수집 완료는 각각 확인합니다.
- `pipeline.real_estate_fetch --property-type officetel`은 반드시 별도 `--root`에 수집합니다. 아파트 체크포인트의 재사용은 오류로 차단합니다. 기본값은 기존 `apartment`입니다.
- 오피스텔에는 아파트 `aptSeq`를 만들어 넣지 않습니다. 공식 명세에 단지 식별자가 없으므로 현재 `complex_id`, `source_complex_id`, 좌표는 미연결로 유지합니다. 같은 이름이나 복합건물이라는 이유로 아파트와 합치지 않습니다.
- 취소 거래, 동일 속성의 여러 거래, 보증금·월세 단위를 보존합니다. 두 유형은 원본·정규화·통계·검색·비교·공유 상태에서 구분해야 합니다.
- 현재 공개 거래는 아파트입니다. 오피스텔 전환 화면·지역과 법정동 유지·연결 전 상태는 공개했고, 수집·정규화 경로도 구현했습니다. 실제 인증·단지 연결·유형별 공개 릴리스·거래 필터는 아직 연결하지 않았습니다. 기존 아파트 게시기는 오피스텔 장부를 거부합니다.
- 아파트 우선 흐름을 먼저 완성하고, 동일한 지역 우선순위로 오피스텔을 추가합니다. 자료 연결 전에도 화면과 조작을 만들되 실제 데이터나 연동이 완료됐다고 표시하지 않습니다.
