# 서울 전월세 공식 연도 ZIP 검증 — 2026-09-28

## 판정

서울 열린데이터광장 OA-21276의 **2011년·2025년 공개 ZIP 두 개는 다운로드와 전체 내용 검증에 성공**했다. 서울 과거 전월세의 초기 확보를 빠르게 하는 독립 원천 후보다. 다만 거래별 영구 ID, MOLIT 단지 ID, 취소·해제·정정 필드가 없으므로 **현재 MOLIT 수집 완료 상태나 거래 이력의 동등한 대체물로 사용할 수 없다.** 아직 서비스에 연결하거나 기존 자료와 합산하지 않았다.

2025년 원본에는 접수연도와 다른 계약연도, 완전히 같은 23개 필드의 반복 행이 존재한다. 이들을 계약연도별 파일이라고 취급하거나 내용 해시로 자동 중복 제거하지 않는다. 원천의 한계를 보존하는 별도 계약과 검증이 필요하다.

## 공식 출처와 권리

- [서울시 부동산 전월세가 정보 OA-21276](https://data.seoul.go.kr/dataList/OA-21276/A/1/datasetView.do): 국토교통부 공개자료를 연계한 서울시 자료. 공공누리 1유형, 출처표시 조건으로 상업적 이용·변경 가능. 원문은 FILE 탭을 빠른 다운로드 방법으로 안내한다.
- 페이지에서 확인한 범위는 2011~2025년 ZIP 15개다. 전체 15개는 다운로드하지 않았다. Sheet는 당년·최대 1,000건, API는 최근 3년만 제공한다는 안내가 있어 과거 확보에는 첨부파일이 적합하다.
- 페이지의 데이터 갱신일과 첨부파일 수정일은 다르다. 이번 2011 첨부 수정일은 **2022-05-18**, 2025 첨부 수정일은 **2026-02-04**다. 페이지에 매일 갱신한다고 표시되어 있어도 오래된 ZIP까지 최신 정정을 반영했다고 간주하지 않는다.
- 국토부 RTMS 웹 시스템의 자동추출 경로는 사용하지 않았다. 별도 서울시 공식 첨부파일에 노출된 다운로드 동작만 사용했다.

## 다운로드와 보존

공식 페이지의 `downloadFile('24')`(2011), `downloadFile('40')`(2025) 링크 및 같은 HTML의 `frmFile` 폼을 확인했다. 폼이 안내한 다음 경로로 파일만 읽었다. 신청·등록 요청이 아니다.

```text
POST https://datafile.seoul.go.kr/bigfile/iot/inf/nio_download.do?&useCache=false
infId=OA-21276&seqNo=&seq=24&infSeq=3   # 2011
infId=OA-21276&seqNo=&seq=40&infSeq=3   # 2025
```

원본·출처 HTML·요청 메타데이터·수집시각·내용 SHA·분석 요약은 로컬 전용 `.local/seoul-rent-bulk-20260928/`에 보존했다. 키·로그인 세션은 사용하지 않았다. 원본 주소·건물명 등 개별 행은 이 문서에 전재하지 않는다. 신규 폴더를 생성했으며 기존 파일을 덮어쓰거나 삭제하지 않았다.

| 연도 | ZIP 바이트 | 비압축 바이트 | 원본 ZIP SHA-256 |
|---|---:|---:|---|
| 2011 | 3,603,057 | 39,105,717 | `09fd4230b4cd0abf67c24b4d192a5c61e1819a6f6ce640fa7c51b4e0bf3a0c7e` |
| 2025 | 26,675,279 | 155,574,646 | `d7a887488fb89eb337e134d4ce724b0279b207ec4d4f54e6ee3fb95c6fa49d52` |

합계 ZIP **30,278,336바이트**, 비압축 **194,680,363바이트**, 파일 **2개**로 요청한 40MiB/512MiB/100파일 제한 안이다. 절대경로·상위경로 이동·드라이브 경로·심볼릭 링크를 거부하는 ZIP 목록 검사를 통과했다. 디스크에 압축 해제하지 않고 CP949 텍스트를 스트림으로 끝까지 읽어 CRC 검증까지 완료했다. 2011은 `.txt`, 2025는 `.csv`이지만 두 파일 모두 쉼표 구분, 같은 23개 헤더다. ZIP 구형 파일명 인코딩 차이는 멤버 이름으로 경로를 생성하지 않아 영향을 주지 않는다.

아파트 선별은 이름 추론 대신 명시적인 `건물용도` 값으로 가능하다. 연립다세대·단독다가구도 원본에 들어 있으나 우리 서비스의 아파트·오피스텔 범위에 합치지 않는다.

2025 파일의 아파트 계약연도 분포는 2023년 611행, 2024년 21,204행, 2025년 423,139행, 2026년 29행이다. 이 분포는 원천값의 관찰 결과이며 미래 계약 또는 원천 정정 여부를 임의 판정하지 않았다. 접수년도는 전체 행에서 2025로 기재되어 있다. 전체 자료에서 자치구코드가 비어 있는 5행도 있어 단순 고유값 수 26을 서울 26개 구로 해석하면 안 된다.

2011의 계약기간·신규계약구분·갱신청구권사용·종전보증금·종전임대료는 전체 행에서 비어 있다. 2025 아파트의 신규계약구분은 신규 235,719행, 갱신 170,071행, 빈값 39,193행이다. **갱신은 임대차 계약 유형으로, 자료의 정정·취소 또는 최신 재수집 여부를 뜻하지 않는다.**

헤더에 거래 ID·신고번호·일련번호, MOLIT 아파트 단지 ID, 취소·해제·정정 필드는 없다. `자치구코드`·`법정동코드`는 지역 식별자이며 단지나 개별 거래 ID가 아니다. 취소 필드가 없다는 사실은 취소된 거래가 전혀 없다는 의미가 아니다. 반복 행도 원천 중복인지 서로 다른 실제 거래인지 이 파일만으로 확정할 수 없다.

## 연결 설계와 남은 검증

1. **별도 출처 계약:** `seoul-rent-bulk` 원천으로 관리하고 OA-21276, ZIP SHA, 첨부 수정일, 내려받은 시각, 인코딩, 원본 멤버와 행 번호를 보존한다. `ZIP SHA + 멤버 + 행 번호`는 파일 내부 출처 식별자일 뿐 영구 거래 ID로 표시하지 않는다.
2. **계약월로 재분할:** 원천 접수연도는 유지하면서 실제 계약일로 월별 뷰를 만든다. 2025 파일 하나를 받았다고 2025년 계약 자료 전체가 완료됐다고 판정하지 않는다. 인접 접수연도 파일과 공표 범위 확인이 필요하다.
3. **정밀 정규화:** 돈은 원천 만원 단위를 별도 보존하며 정수 원화 변환, 면적·날짜·지역코드 검증을 수행한다. 빈값은 미확인으로 남긴다. 코드 결측·날짜 불일치·반복 행을 별도 감사한다. 이번 작업은 헤더·형식·분포 검증이며 금액과 면적 전수 의미 검증까지 마친 것은 아니다.
4. **단지 연결:** 기관 ID가 없으므로 법정동·지번·건물용도·건물명 등 다중 근거를 검토한 연결 테이블이 필요하다. 동명 단지나 모호한 다대다 연결은 확정 위치로 채택하지 않는다.
5. **중복·취소 경계:** 기존 MOLIT API 거래와 자동 합산·내용 해시 중복 제거하지 않는다. 원천끼리 같은 기간을 비교한 뒤 식별 불가 사례를 남기고 사용자 통계에서 이중 계산하지 않는 정책이 필요하다. 취소 확인이 불가능한 자료를 취소 검증 완료로 표시하지 않는다.
6. **화면 상태 분리:** 공식 연도 파일 확보, 정규화 완료, 단지 연결, 계약월 확보, 취소·정정 검증을 각각 기록한다. 현재 수집 장부의 `complete`를 이 파일 도착만으로 변경하지 않는다.

## 공간과 속도 판단

두 공식 다운로드로 서울 2개 접수연도의 1,401,008행을 확보했다. 매 구·월마다 API를 호출하는 방식보다 초기 전송 요청 수를 줄이는 경로는 실제 존재한다. 단, 같은 계약기간·취소 상태·단지 ID 범위가 아니므로 동등 자료의 속도 배수는 측정하지 않았다.

보존 원본은 ZIP 30.28MB이고 비압축 텍스트는 194.68MB다. ZIP 원본 하나와 체크섬·파서 버전·행 위치를 보관하고 파생 산출물을 다시 만드는 방식이 공간상 유리하다. 현재 아카이브가 사용하는 zlib 이후 Base64 저장에 이미 압축된 ZIP을 넣으면 추가 압축 이득은 작고 Base64 크기는 약 4/3로 증가할 수 있다. 파생 JSON·색인·스냅샷도 추가 공간을 차지하므로 이 두 파일만으로 9개 권역 전체가 남은 저장 한도에 들어간다고 추정하지 않는다.

공식 서버의 파일이 나중에 변경될 수 있으므로 URL만 남기는 것은 원본 보존을 대체하지 못한다. 기존 원본·스냅샷 삭제, 아카이브 구조 변경, 원격 수집 변경, 나머지 연도 대량 다운로드는 수행하지 않았다.
