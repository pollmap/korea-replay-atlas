## 이번 변경의 확인 방법

1. 지역 선택 후 단지 찾기에 ‘삼익’, 매매가 ‘5–8억’을 입력합니다.
2. 결과의 강변삼익을 연 뒤 지역 목록으로 돌아오면 검색어와 가격 조건이 유지됩니다.
3. 단지정보에서 신고 원문의 주소·건축연도·공식 식별번호를 확인합니다.
4. 비교 담기 → 비교 메뉴에서 동일 전용면적을 선택합니다. 미선택 시 중앙값을 임의로 보여주지 않습니다.
5. 조건 입력에서 Escape를 누르면 조건 창이 닫히고 해당 필터 버튼으로 초점이 돌아옵니다.

로컬 UI는 기존 로컬 5개월 데이터, 공개 후보는 기존 불변 게시 데이터에 연결되므로 데이터 범위를 혼동하지 않습니다. 새 데이터 게시·전국 좌표 검증·10년 수집·10배 성능 개선은 이번 UI 변경으로 완료되지 않습니다.
