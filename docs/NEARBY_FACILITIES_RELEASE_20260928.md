# 주변 시설 연결과 거래 보존 — 2026-09-28

대상은 경기·서울·인천·천안·아산·세종·청주·대전·부산이다. 기존 3D 코드와 자료는 변경하지 않았다. 이 문서의 구현·로컬 검증은 공개 배포 성공과 구분한다.

## 실제 사용 흐름과 개선

[호갱노노 공개 단지](https://hogangnono.com/apt/5Rsb1/0/1)에서 단지 선택 뒤 주변 교통·학교 목록, 학교급 전환, 시설 이름·거리의 배치를 확인했다. 중학교 탭에서 대화중·오마중·한수중이 표시되는 조작까지 확인했다. 전 서비스·유료·로그인 기능을 모두 검토했다는 의미가 아니다. 기존 아실·네이버 비교는 [인수 기준](PROPERTY_PARITY_ACCEPTANCE_20260927.md)을 유지한다.

우리 화면은 **단지 → 주변 → 분류·반경 → 시설 → 지도 위치**를 연결했다. 실거래·단지정보·주변을 왕복해도 선택 단지를 유지한다. 시설로 이동한 뒤 `기준점 보기`로 조회 기준 위치에 돌아올 수 있다. 반경은 500m·1km·3km이며 이름순·가까운순을 제공한다.

조회 기준은 검증된 단지 위치 또는 사용자가 직접 선택한 지도 중심점이다. 서울 제공점의 미확인 CRS를 확정 단지 위치로 승격하지 않았다. 수동 기준점에는 단지 위치와 다를 수 있음을 표시한다. 시설 면·선의 대표점은 입구 위치가 아니며 직선거리는 도보 시간·배정 학교를 뜻하지 않는다.

791개 불변 파일, 총 30,465,475바이트다. 페이지 전체를 내려받지 않고 3km 범위에 겹치는 셀만 SHA·크기 검증 후 읽는다. 실제 9개 대표점 조회의 최대는 11파일·1,327,621바이트였다. 다운로드는 기존 공통 4슬롯을 공유하며 한 조회는 64파일·4MiB로 제한한다. 이 수치는 데이터 조회 검사이며 첫 화면 속도나 GPU 프레임 측정이 아니다.

시설 목록 DOM은 20행으로 제한하고 모든 결과에 이전/다음 페이지로 접근한다. 페이지를 바꾸면 목록 제목으로 초점을 옮긴다. 모바일에서 단지·시설의 지도 버튼을 누르면 패널을 접어 표식을 보여주고, 펼치기 버튼으로 초점을 옮긴다. 다시 펼쳐도 단지·시설 조건을 유지한다. 개발계획·학교 배정·출퇴근 경로 API는 이번 POI 연결로 구현된 것으로 취급하지 않는다.

원천·파생 데이터베이스는 ODbL이며 자체 MIT 코드와 구분한다. 시설별 원본 링크와 출처·기준일을 표시한다. [원천 검토](PROPERTY_POI_SOURCES_20260928.md), [외부 자료 고지](../THIRD_PARTY_NOTICES.md)를 함께 유지한다.

## 거래 보존과 속도

수집기가 재조회를 대기할 때 이전 검증 거래를 공개 목록에서 제외하던 결함을 고쳤다. 이전 스냅샷과 원본 XML의 해시·재정규화 일치를 확인한 경우에만 이전 성공 자료를 유지한다. 게시 자료와 수집 장부의 상태는 별도 집계하고 마지막 성공 시점을 표시한다. [실제 게시 차이 감사](PROPERTY_PUBLICATION_GAP_20260928.md).

후보 `property-87d1c67336e97209`는 2,276,757행·42,988단지다. 이전 8,365개 작업을 모두 보존하고 신규 307작업·167,477행 및 기존 월 재조회 증가 420행을 반영했다. 갱신 대기 466작업·83,024행은 거래 전체 내용의 다중집합·적격 행수·원래 수집시각까지 이전 공개본과 일치한다. 4,853개 파일의 SHA·크기와 원천 XML 재정규화를 검사했다.

동일 릴리스의 단지 기본정보 842개·지도 제공점 848개·가격 마커 847개를 원천에서 다시 생성하고 이전 ID·값·형상과 비교했다. 누락·값 변경은 없으며 미확인 좌표 기준은 계속 미확인으로 유지한다. 기존 `property-54bf1817fdcc7bd9` 공유는 검증된 불변 배포로 복원하고 최신 자료로 대체하지 않는다.

완전히 검증된 선택 단지·월별 거래만 별도 캐시한다. 최대 256개월·20,000행·직렬화된 키와 거래 4MiB이며 원천 전체 응답을 중복 보관하지 않는다. 실패·부분·중단된 월은 캐시하지 않는다. 기간을 왕복할 때 이미 확인한 월의 재다운로드·파싱을 줄인다. 단위 검사에서 동일 월 두 조회의 요청이 2회에서 1회로 감소했으며 전체 지도 속도 배수로 환산하지 않는다.

새 수집 스냅샷에는 XZ를 적용했다. 기존 JSON/gzip과 원본은 보존하고 복원 호환성을 유지한다. 실제 40개 큰 파일 표본은 gzip 대비 36.57% 작았으나, 지정 지역 20년 수집·무료 장기 보관 완료를 의미하지 않는다. [압축 검증](PROPERTY_STORAGE_COMPRESSION.md), [수집 장부·용량](PROPERTY_HISTORY_STATUS_20260928.md).
