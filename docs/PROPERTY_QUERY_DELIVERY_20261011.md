# 조건 검색·릴리스 검색 색인·상세 통합

2026-10-11. PR117의 중앙값 차트 변경을 이어받은 코드 후보이며 공개 반영과 구분한다.

## 구현

- `송파 12억 이하 국평`을 지역·최근 유효 거래 예산·전용 84~85㎡ 조건으로 해석한다. 거래 유형을 쓰지 않으면 기존 선택을 유지한다. 입력 중에는 지도 조건을 바꾸지 않고 Enter 또는 조건 적용으로 한 번에 반영한다.
- 조건 칩을 누르면 해당 입력을 수정한다. 동명 지역은 선택하며 미해석 문구·중복 조건·면적 기준 모호성을 무시하지 않는다. 월세 금액을 임의로 보증금 또는 월 납부액으로 확정하지 않는다.
- 기존 이름·주소 검색, 공유 상태와 필터를 재사용한다. 새 조건 적용은 뒤로가기 가능한 이력을 만든다. 매매 예산으로 과거 계약 행을 삭제하지 않는다.
- 상세 기본 메뉴는 거래·단지정보·주변이다. 관리비는 단지정보, 학교는 주변에 연결한다. 기존 fees/schools 공유 링크와 비교함은 유지한다.
- PropertyRelease의 선택적 search_index 참조를 검증하고 같은 릴리스의 검색 색인을 읽는다. 기존 공개 릴리스의 번들 색인은 호환 경로로 유지한다. 다른 릴리스의 이전 검색 결과를 표시하지 않는다.
- 게시기는 대상 권역이 모두 있는 경우 이미 읽은 단지 정보로 검색 색인을 함께 생성한다. 원본 추가 다운로드나 거래 재파싱은 발생하지 않는다. 검색 코드 변경은 게시 입력 식별자에 포함한다.
- 게시 정책 v6로 신규 산출물에 별도 ID를 부여한다. 기존 준비 후보를 수정하거나 새 버전으로 덮어쓰지 않는다.

## 검증

- 검색·공개 참조 관련 웹 54개 통과. 후속 입력 범위 보강 후 검색·자료 계약 41개 재확인.
- 웹 전체: 1,271개 통과, 기존 배포 검사 2개가 Windows 5초 제한시간 초과. 해당 배포 파일을 단독 실행하고 제한시간 30초로 두었을 때 28개 모두 통과. 기본 제한시간의 Linux CI는 별도 확인한다.
- 타입·린트·프로덕션 빌드 통과. 새 검색 색인의 게시·재사용 및 기존 감사 색인과의 일치 검사 2개 통과.
- 실제 브라우저·CI·공개 반영은 마지막 실행 기록과 PR 상태로 별도 판정한다.

## 아직 남은 작업

1. PR117의 중앙값 차트와 이번 조건 입력·상세 화면의 PC 조작 검사, 병합 및 Pages 공개.
2. 준비된 property-7f25dea9e9be919f 정정 후보의 공개 연결. 확인 당시 공개는 property-ceeff63959643461이다. 새 요약 분포와 검색 색인이 이전 준비 후보에 이미 들어 있다고 표현하지 않는다.
3. 후보 큐의 실제 Pages 게시기·지속 운영 자격증명 연결. 현재 CLI는 후보 준비까지만 수행한다. 공통 배포 잠금·부모 artifact 검사·collection 보존이 필요하다.
4. 동일 입력 무작업 처리는 존재하지만, 변경된 날 모든 월별 파일이 내용 단위로 재사용되는 구조의 완료는 별도다.
5. 전 권역 단지 위치·기본정보·관리비 보강, 관계 조회 운영 API, 공개 성능 인수.

이 변경은 수집기 재실행, 기존 공개 포인터 변경, 원본 삭제, 새 유료 의존성 도입을 하지 않는다.
