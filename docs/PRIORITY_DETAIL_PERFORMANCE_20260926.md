# 수도권·충청권 상세 2D와 타일 재사용

서울·인천, 경기, 대전·세종·청주, 나머지 충남·충북을 상세 2D 지도와 성능 검증의 우선 범위로 둡니다. 3D 코드·자료는 변경하지 않습니다. 기존 전국 범위도 유지합니다. 상세 배경은 아파트·오피스텔 중심 서비스의 위치 이해를 지원하며 일반 주택 거래로 상품 범위를 확장하지 않습니다.

## 건물 자료

공개 지도는 서울·인천 원본 건물 468,104개와 상세 도로 216,257조각을 포함합니다. 새 후보는 같은 감사된 Overture/OSM 원본과 SGIS 경계로 7개 시도의 범위를 넓힙니다. 청주는 충북 범위에 포함됩니다. 이는 기존 허용 원본의 2D 변환이며 새 건물·단지 좌표를 추측하지 않습니다.

```powershell
.venv/Scripts/python.exe -X utf8 -B -m pipeline.map_tiles_regional --baseline .local/map-tiles-20260920/mobile-overview-candidate --output .local/regional-detail-20260926/capital-chungcheong-v1 --regions 서울특별시 인천광역시 경기도 대전광역시 세종특별자치시 충청북도 충청남도
```

선별된 원본 파일은 694개입니다. 소스별 체크포인트 → 타일 생성 → 전 ID 감사 → 넓은 줌 타일 → 앱·데이터 후보 → 브라우저 검증 순서를 통과해야 공개 범위를 바꿉니다. 배치를 시작한 사실을 데이터 배포 완료로 취급하지 않습니다.

## 반복 압축 해제 제거

기존 프로토콜은 압축 묶음만 캐시하므로 같은 타일 요청에도 PMTiles 판독과 gzip 해제를 반복했습니다. 해제 타일 LRU를 추가해 동일 릴리스·주제·좌표의 검증된 결과를 재사용합니다. MapLibre가 전달받은 버퍼의 소유권을 가져가도 캐시가 손상되지 않도록 복사본을 반환합니다.

- 데스크톱: 압축 48MiB + 해제 16MiB. 모바일: 압축 24MiB + 해제 8MiB. 두 캐시 합계는 기존 64/32MiB를 유지합니다.
- 해제 결과는 512개 항목 상한도 적용합니다. 디렉터리 캐시는 기존 별도 4MiB 상한을 유지합니다.
- 취소·종료 요청은 캐시를 우회하지 않으며, 릴리스 전환 시 전체 캐시를 해제합니다. SHA 검증과 타일 크기 제한은 유지합니다.

## 측정 범위

`scripts/benchmark-map-tile-cache.ts`는 동일 원본 타일 바이트에 대해 네트워크 수신이 끝난 뒤 캐시 미사용/사용 경로를 각각 10회×100호출 비교합니다. 출력에 타일 좌표·해제 크기·SHA·중앙값·P95·상한을 남깁니다. 원본 처리 배치와 병행한 국소 Node 측정이므로 GPU 프레임·첫 지도 진입·모바일 성능이나 화면 전체 10배 달성의 근거로 사용하지 않습니다. 실제 브라우저와 통제된 종단간 비교는 별도 판정입니다.

서울 밀집 타일 `buildings-overview-0/12/3493/1585`(해제 804,913B)의 호출당 중앙값은 6.106ms에서 0.207ms로 줄었습니다(29.54배). 10개 반복 묶음의 호출당 평균 P95는 7.227ms에서 0.395ms였습니다. 각 개별 호출의 P95가 아니며 캐시 적중 시의 국소 결과입니다. 동일 바이트 SHA를 대조했습니다.

로컬 프로덕션 빌드에서 확대 버튼 3회 후 건물 윤곽을 시각 확인했습니다. 오류 0, 해제 캐시 적중 42회, 압축 약 20.1MB·해제 약 16.5MB로 상한을 지켰습니다. 이동 155표본 P95 29.1ms를 관찰했지만 한 장면·비통제 측정이므로 전체 성능 인수로 취급하지 않습니다. 버퍼 전송·변조 격리, 메모리/항목 상한, 취소, 기존 계약을 포함한 웹 테스트 988건과 타입·린트·빌드를 통과했습니다.
