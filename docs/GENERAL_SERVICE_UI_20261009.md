# 일반 사용자 아파트 탐색 개편 — 2026-10-09

## 범위

기존 지도·목록·실거래·비교 구조를 유지한다. 개인 조사용 collection의 가격·면적 중심 정보 위계와 선택 강조를 참고했으며 개인 예산, 매물 호가, 사진과 조사 기준은 일반 서비스의 자료에 편입하지 않았다. 대표색은 최신 사용자 결정에 따라 보라색·흰 배경이다.

## 변경

- 48px 상단 아래 44px 공통 조건 줄: 지역·법정동, 거래 유형, 예산, 전용면적, 기간, 상세조건.
- PC 패널의 중복 검색·필터를 제거하고 결과 수·정렬 다음에 후보를 표시한다.
- 후보 행: 이름 → 최근 유효 실거래 가격·전용면적 → 계약일 → 주소·건축연도.
- 상세 메뉴: 실거래·단지정보·주변·비교. 관리비·학교·지역 분석·계산은 더보기에서 같은 위치로 이동한다.
- 선택 아파트를 진한 보라 배경과 흰 글자로 표시하며 지역 표식보다 위에 그린다. 경계 설정은 접힌 버튼으로 제공하고 실제 경계 강조는 유지한다.
- 예산 창을 연 뒤 거래 유형·조건을 바꾸면 이전 임시 값은 폐기한다. 구 선택 중 초점은 지역 선택창 안에 남는다.
- 예산은 후보 단지의 최근 거래 조건이다. 선택 단지의 과거 거래를 예산에 맞춰 삭제하지 않는다.
