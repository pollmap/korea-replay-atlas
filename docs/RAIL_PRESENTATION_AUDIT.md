## 계획·공사 노선

기존 수집기는 `railway=construction/proposed`를 제거했습니다. 2026-09-16 PBF의 읽기 전용 감사에서 501개 way가 해당 태그를 가지고 있었습니다. 유형까지 rail/subway/light_rail/tram로 명시된 것은 공사 345개, 계획 57개입니다. 노선 한 개가 여러 way로 나뉘므로 이 숫자는 사업·노선 수가 아닙니다.

후속 후보 추출은 `construction:railway`/`proposed:railway`와 기존 철도 유형에 붙은 명시적 공사·계획 태그도 포함했습니다. 실제 산출물은 **723개 way(공사 644·계획 79), 원본 정점 8,953개, 1,343,476바이트, 누락 노드 격리 0건**입니다. 후보 SHA-256은 `9b2b0b12effec0e14e8ca6207ae893f79ba268e24187b4ddd835927eeff41774`입니다. 초기 단일 태그 감사와 집계 범위가 다릅니다.

`pipeline.rail_candidates`는 원본 노드 순서·좌표·OSM 식별자·태그·원천 SHA를 보존하는 검토 후보를 만듭니다. 운영 중 경로·공식 예정 노선 목록에 자동 게시하지 않습니다. `official_status_verified=false`, `publication_state=review_only`, `eligible_for_operating_routes=false`이며, 원천 개통일 태그가 있어도 검증된 개통일로 승격하지 않습니다. 누락·비정상 노드가 있으면 해당 way 전체를 격리하고 직선으로 연결하지 않습니다. 공사·계획·폐선 태그가 섞인 선로는 기존 심도 보간과 운영경로용 철도 추출에서 배제합니다.

실행:

```powershell
.venv/Scripts/python.exe -m pipeline.rail_candidates
```

산출물은 `.local/review/rail-candidates/`의 후보 GeoJSON과 `audit.json`입니다. 공식 사업 단계·노선 위치·개통일의 검증과 게시용 타일 연결은 별도 남은 작업입니다. OSM에 누락되거나 오래된 사업이 있을 수 있으므로 전국 예정 노선 확보 완료로 판정하지 않습니다.
