# 2D 화면 간소화 — 2026-10-03

## 변경 범위

- 흰색 바탕과 파란색 선택 강조를 유지하고 2D의 로딩·미연결 화면 그라데이션을 제거합니다.
- 브랜드 설명, 반복된 주변 필터 요약, 중복 외부 지도 링크, 미연결 기능의 예고 문장을 제거합니다.
- 개인정보 전달·원천 기준 설명은 닫힌 펼침 영역으로 옮깁니다. 오류·재시도·미수집 상태, 단위와 수집 범위는 남깁니다.
- 버튼은 색상·테두리 hover만 사용하며 이동·확대 애니메이션을 사용하지 않습니다. 지도 표식의 인라인 좌표 변환과 모바일 재열기 버튼의 중앙 정렬은 유지합니다.
- 3D 렌더러·원본·지도 자료, 데이터 릴리스는 변경하지 않습니다.

## 검증

- 타입·린트 통과. Vitest 94개 파일, 1,148개 테스트 통과. 프로덕션 빌드 통과.
- 변경 전 대표 주소와 변경 후보를 1280×720의 같은 단지·면적·기간에서 비교했습니다.
- 미연결 주변시설 영역 160→48px. 상세 스크롤 높이 4,283→3,784px. 표시 조건에 한정한 UI 측정이며 지도 성능 개선률이 아닙니다.
- 2D DOM의 그라데이션 0개, 셸·빈 상태 흰색, 문서 가로 넘침 없음.
- 학교/교통/실거래 탭 전환, 비교 담기와 로딩 완료, 대출 입력 1억원·연4%·30년의 월477,415원 출력 확인.
- 학교 버튼은 로딩 완료 뒤 선택 전후 같은 위치·높이를 유지했습니다. 실제 hover에서 transform/animation은 none, brightness(.95), transition 대상은 색상·테두리뿐입니다.
- 단지 외부 지도 링크 그룹 2→1개. 출처·기준일·자료 연결 전·확인 18/36개월 표시와 외부 지도 전달 안내를 유지합니다.
- 새 데이터 확보나 위치 검증 완료를 의미하지 않습니다.
