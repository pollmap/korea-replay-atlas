# 천안 철도 라벨 오류 검증

프로덕션 상세 지도 후보 `map2d-bafa61b25c500d34c8f7`의 천안 장면(127.113, 36.815, zoom 15)에서 `vector-rail`이 `Cannot read properties of undefined (reading 'x')` 오류를 재현했습니다. 요청 파일은 정상 제공됐고, 새로고침해도 오류 1건이 반복됐습니다.

기존 철도 심벌은 점과 선에 모두 `symbol-placement: point`를 적용했습니다. MapLibre 6.10.0의 `symbol_layout.ts`는 이 경로에서 선의 첫 분할 꼭짓점에 바로 접근합니다. 노선 이름은 선 중앙에, 역 이름은 점에 배치하도록 형상 필터와 라벨 레이어를 분리했습니다. [공식 배치 사양](https://maplibre.org/maplibre-style-spec/layers/#symbol-placement)을 따르며 선·역의 형상, 원본 ID, 타일 바이트와 색상 매핑은 유지합니다.

동일 데이터·장면의 로컬 브라우저 재검증에서 오류는 1건에서 0건으로 바뀌었습니다. 이 결과는 문제 경로를 피하는 표시 수정의 근거입니다. 전체 철도 15묶음의 SHA와 95,375개 선 피처를 원시 명령/좌표로 검사했으나 빈 선이나 고유 좌표 1개인 선은 발견하지 못했습니다. 따라서 원본이 잘못됐거나 빈 선이 근본 원인이라고 단정하지 않습니다.

관련 스타일 계약·형상 분리·색상·MapLibre 사양 검증 10개를 통과했습니다. 프로덕션 빌드·공개 후보 및 다른 지역 회귀는 별도 기록으로 판정합니다. 지형·건물 변환 배치와 3D는 변경하지 않았습니다.

로컬 프로덕션 빌드에서도 동일 천안 장면의 지도 오류 0건을 재확인했습니다. 서울·인천·수원·대전·세종·청주 대표 장면에는 상세 건물과 도로가 표시됐고 오류는 0건이었습니다. 이는 선정 장면의 화면 검증이며 지역 전체의 현실 건물 전수 정확성을 뜻하지 않습니다.

후속 교차선 라벨 회귀를 포함한 전체 웹 검사 1,006개 중 1,002개가 첫 실행에서 통과하고 파일 입출력 검사 4개가 5초 제한에 걸렸습니다. 대량 타일 생성과 병행하던 실행이었으며, 해당 두 테스트 파일을 worker 1개로 분리해 제한 시간을 바꾸지 않고 23개 모두 통과했습니다. 브라우저 성능 인수 수치로 이 실행 시간을 사용하지 않습니다.

수인분당·대전 색상과 상수 시간 ID 조회를 포함한 후속 전체 검사는 1,008개 중 1,007개가 통과하고 같은 전국 경계 캐시 검사가 다시 5초 제한에 걸렸습니다. 이 검사는 모든 지역 fixture를 순회하며 메모리 상한을 검사하므로, 해당 검사에만 30초 실행 여유를 주었습니다. 메모리·해시·좌표 단언과 실제 서비스 성능 목표는 바꾸지 않았습니다. 관련 경계·색상·레이어 22개 검사 모두 통과했습니다.

최종 문자 대비 회귀 14개, 타입·전체 린트·프로덕션 빌드를 통과했습니다. 1280×720 수원 장면에서 노란 수인분당선과 어두운 노선명을 함께 확인했고, 대전역 장면에서 녹색 1호선을 확인했습니다. 두 장면 모두 지도 오류 0건입니다. 공개 후보와 대표 주소 검증은 배포 단계에서 별도로 수행합니다.
