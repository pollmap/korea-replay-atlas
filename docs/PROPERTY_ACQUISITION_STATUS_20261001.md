오피스텔 [매매 15126464](https://www.data.go.kr/data/15126464/openapi.do)의 현재 공식 페이지는 무료·이용허락범위 제한 없음·개발계정 10,000호출·자동승인으로 표시합니다(2026-10-01 확인). 해당 공개 이용조건은 **이 계정의 API 응답 성공을 뜻하지 않습니다.** 기존 아파트 장부를 오피스텔로 바꾸거나 오피스텔 거래를 아파트 통계에 합치지 않았습니다. 실패 확인 뒤 반복 호출하지 않았습니다.

재현 도구는 `pipeline.real_estate_history_audit`입니다. 날짜별 240개 완료 월과 잠정 월을 별도로 산출하므로 9월 기준 48,160개(당월 포함) 분모를 10월 완료 월 기준 분모와 그대로 비교하지 않습니다.

## 미게시 수집분의 전수 감사

`property-51bfb7ca79924838` 후보는 원본 페이지를 전부 재파싱하고 SHA를 검사해 **3,161,421개 원천 거래 행**, 43,250개 원천 단지 ID를 보존했습니다. 5,850개 파일·3,245,552,542B입니다. 이전 공개 `property-8deba5b9951e48da`의 **2,494,342개 거래 ID가 모두 남아 있고 신규 667,079개**, 누락 0개를 별도 전수 대조했습니다. 후보 생성과 공개 전환은 별도이므로 이 수치를 실제 공개 범위로 보고하기 전에 배포 검증이 필요합니다.

동일 후보의 월별·단지별 전용면적 요약은 적격 원천 3,113,850개 행을 대표하고 비적격 47,571개는 통계에서 제외해 원문으로 보존합니다. 원문 파일 5,850개 전체의 SHA와 거래 ID를 검사했습니다. 단지별 512KiB 묶음은 전체 지역·월 파일을 받을 필요를 줄입니다. 헬리오시티의 현재 수록 18개월·612개 요약 행을 조회한 자료량은 2개 묶음·1,046,342B였으며, **20년 연속 확보나 전 구간 성능 달성을 의미하지 않습니다.**

새 후보의 서울 공식 주소·단지명 연결도 별도 재검증했습니다. 원천 2,893개 서울 등록 단지 중 844개 위치 후보가 연결됐고, 839개에 공개 가능한 공식 기본정보가 있습니다. 이전 버전의 연결은 그대로 보존합니다. 위치의 좌표계·점 의미는 여전히 `provider_xy_crs_unconfirmed`이며 건물 경계나 검증된 정확한 단지 좌표로 승격하지 않았습니다.

위 원문 후보를 보존한 채 새 `property-8879dff1b31ac5f0`은 최대 4MiB의 월별 거래 묶음으로 만들었습니다. **거래 ID 전체 3,161,421개가 동일하게 남고 파일 수는 5,850→1,406개**입니다. 연결 요약 `summary-49ad802d41baf9f8`은 월별 파일을 7,560→2,734개로 줄이고 단지별 512KiB 조회 묶음을 유지합니다. 공개 전환은 배포에서 이 릴리스와 요약을 함께 고정한 뒤 판정합니다. 서울 공식 기본정보·탐색 인덱스·위치 후보도 새 거래 릴리스로 재생성했습니다.
