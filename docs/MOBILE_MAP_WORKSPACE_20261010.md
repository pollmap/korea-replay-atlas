# 모바일 지도 탐색 개선 — 2026-10-10

## 문제와 수정

사용자가 제공한 맛동산·아실 모바일 화면을 기준으로 지도 가림과 조작 흐름을 수정했다. 참고 이미지에서 확인한 배치는 상단 검색·조건, 지도 위의 작은 도구, 하단 주요 탐색이다. 아실의 비공개 기능이나 매물 데이터를 복제한 작업은 아니다.

- 모바일 `목록 보기` 버튼에 위·아래 위치가 동시에 적용돼 화면 높이만큼 늘어나는 결함을 제거했다.
- 표식 선택기를 작은 단일 컨트롤로 고정하고 검색·조건 창의 가로 넘침을 제거했다.
- 하단에서 지도, 목록·상세, 관심, 비교를 전환한다. 지도 복귀 시 선택·예산·면적·기간을 유지한다.
- 목록·상세는 접힘, 중간 높이, 전체 높이를 지원한다. 새 단지 선택 시 중간 높이로 열린다.
- 단지 공유 링크는 작은 화면에서도 상세를 바로 연다. PC의 단지정보·주변 공유 상태도 모바일에서 복원한다.
- 관리비·학교·지역 분석·비용 계산을 상세의 추가 메뉴에서 연다. 기존 공식 자료와 지연 조회를 재사용한다.
- 지도 설정 업데이트 안내를 짧게 바꾸고 닫기 버튼을 제공한다. 같은 안내가 주기적으로 다시 생기지 않는다.
