기존 상세 병합의 추가 float32 반올림 최대 0.344861mm, 기존 반올림 포함 상한 0.556206mm는 유지됩니다. 새 계층은 상세 좌표 재양자화가 없고 상대 변환 연산 오차 상한은 5.77×10⁻⁹m입니다. 이는 수치 연산 오차로서 실제 위치·높이·지형의 정확도를 뜻하지 않습니다. 구조와 감사 경로는 [HIERARCHY.md](HIERARCHY.md), 생성 절차는 [RETILING.md](RETILING.md)에 있습니다.

## 성능과 공개 계약 변경

도로·철도의 일반 형상은 브라우저 Web Worker에서 해석하고 Cesium 배치 Primitive로 생성합니다. 상세 속성은 따로 보관해 선택 때 조회합니다. 화면에 필요한 지역만 적재하고 바이트·정점·메모리 예산과 동시 작업 제한을 적용합니다. 카메라 이동 중에는 해상도·상세도·그림자를 조절하고 정지 후 복원하며, 지속된 성능 저하만 자동 화질 판단에 사용합니다. 시간 재생은 정적 지도 선택과 분리하고 실제 기상 프레임 경계에서 영상을 교체합니다.

CatalogV2는 작은 공개 목록과 지역별 색인을 사용합니다. v1 catalog API는 사전 생성한 파일을 스트리밍하고 coverage는 작은 별도 범위 색인을 읽습니다. 검색은 128개 부분문자 bucket과 98개 record page를 필요한 만큼만 받습니다. [검색 v2 검증](SEARCH_V2.md)에 정확한 정렬 계약과 CPU 측정 한계를 기록했습니다.

공유는 데이터 릴리스와 배포 UUID를 함께 고정합니다. 없는 버전을 최신 자료로 대체하지 않습니다. 무료 정적 묶음은 18,000파일을 목표로 하며 **20,000파일 초과 또는 개별 24MiB 이상이면 검사 실패**입니다. 이전 34,075파일·7.31GB 패키지는 과거 R2 준비 결과이며 현재 정적 배포 완료 수로 사용하지 않습니다.
