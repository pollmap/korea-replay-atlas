## 지표·코드·집계 계약

`context.json`은 `schema_version: 1`, `kind: property-regional-context`이며 다음을 보존합니다.

- 원천 행의 10자리 **행정기관코드**, 전체 명칭, 원본 CSV 행 번호.
- 주민등록 인구·남자·여자 인구는 명, 세대수는 주민등록 세대.
- 세대당 인구·남여 비율은 제공자가 표시한 소수 문자열. 자릿수를 임의로 늘리지 않습니다.
- 기준월, 월말 기준일, 시간대, 실제 조회 완료 시각, 원본 SHA-256과 크기.
- 출처와 미연결 상태. 가격지수·주택 공급량은 `not-connected`입니다.

**모든 행을 합산하지 않습니다.** 청주시 상위 합계와 4개 구처럼 포함 관계인 행이 같이 존재합니다. 전국 정합성 검사는 중복되지 않는 광역 행만 더합니다. 예를 들어 실제 청주시 `4311000000`의 인구 860,215명과 하위 구 수치를 동시에 전국 합계에 더하면 중복입니다. 지역명이나 접두어만으로 시·구를 삭제하지 않고 원본 행을 모두 남깁니다.

현재 `map_join.status`는 `unresolved`, `automatic_legal_code_prefix_join`은 `false`입니다. 행정기관코드, 실거래의 법정동코드, 지도 경계 ID는 기준월별 공식 대응 근거를 검증한 뒤 연결해야 합니다. 세대수를 아파트 수·가구 수·주택 공급량으로 바꾸거나 가격지수로 해석하지 않습니다.

## 실행과 실패 처리

저장소 루트에서 계획만 확인합니다. 기본 실행은 네트워크·파일 생성을 하지 않습니다.

```powershell
.venv/Scripts/python.exe -B -m pipeline.property_context --output .local/property-context-next/candidates
```

공식 자료를 실제 조회하고 새 후보를 만듭니다.

```powershell
.venv/Scripts/python.exe -B -m pipeline.property_context --output .local/property-context-next/candidates --execute
```

기준월을 고정하려면 `--month 202608`을 추가합니다. 최신 공표월은 내려받기 폼의 시작·종료월을 검증해 알아내며, 아직 공표되지 않은 월은 CSV 요청 전에 거부합니다. 과거 월도 응답 헤더가 요청 월과 정확히 같아야 합니다. 자동 월별 실행·수집 워크플로는 이번 변경에 포함하지 않았습니다.

통신은 `jumin.mois.go.kr`의 정해진 HTTPS 경로 세 개만 허용합니다. 리다이렉트·추가 호스트·인증키·쿠키·자동 재시도는 사용하지 않습니다. 요청별 20초 타임아웃, 응답당 4 MiB, CSV당 10,000행 상한을 적용합니다. 실패 응답, 잘못된 열·인코딩·기간, 중복 코드, 수치 충돌은 성공 후보로 저장하지 않습니다.

쓰기 전에 원본으로 정규화 결과와 릴리스 ID를 재계산해 대조합니다. 출력은 현재 프로젝트 `.local` 아래 새 디렉터리만 허용하며 경로 이탈·심볼릭 링크·Windows junction·기존 후보 덮어쓰기를 거부합니다. 디스크 쓰기 중 실패하면 `receipt.json`의 완료 표시가 없는 불완전 후보가 남을 수 있습니다. 자동 삭제·덮어쓰기·게시를 하지 않으므로 그 후보를 배포 대상으로 사용하지 않습니다.

오프라인 검증은 `normalize_csv`, `published_month`, `build_sidecar`로 원본을 재검사할 수 있습니다. 같은 원본과 조회시각이면 같은 결과·릴리스 ID가 생성됩니다.

## 재이용 조건과 남은 연결

[행정안전부 저작권 정책](https://mois.go.kr/frt/sub/a08/copyrightPolicy/screen.do)은 기관이 권리를 가진 공공누리 표시 자료의 재이용과 출처 표시를 안내하고, 표시 없는 자료는 담당 부서 확인을 요구합니다. 이번 CSV 자체에는 공공누리 유형 표시가 없어 `resource_license_mark: "not-present-in-csv"`로 기록했습니다. **무료 다운로드가 가능하다는 사실을 개별 재배포 조건 확정으로 바꾸지 않습니다.** 해당 자료의 정확한 재이용 조건을 확인한 뒤 공개 정적 후보로 승격해야 합니다.

이 단계에서 완료한 것은 공식 무키 원천 연결·실제 원본 보존·수치 검증·지역별 정규화 sidecar입니다. 공개 지도에 결합, 가격지수·주택 공급 원천 연결, 시계열 누적, 공식 코드 대응표, 개별 재배포 조건 확인, UI·배포는 아직 별도 작업입니다. VWorld 좌표·API 키·개인 계정 자료는 사용하지 않았습니다.
