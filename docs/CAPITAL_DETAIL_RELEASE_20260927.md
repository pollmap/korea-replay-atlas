## 초기 자료 준비의 후속 변경

기존 흐름은 지도 catalog와 부동산 manifest를 모두 받은 뒤 지역 목록을 요청했습니다.
새 로더는 지도 catalog와 `부동산 manifest → 지역 목록`을 병렬로 처리합니다.
작은 manifest가 먼저 도착하면 지역 목록은 큰 지도 catalog를 기다리지 않습니다.
화면에 전달하는 시점은 세 문서의 해시·스키마·릴리스 검증이 모두 끝난 뒤입니다.

실패 또는 화면 이탈 시 해당 로더의 남은 구독을 취소하고, 다른 화면에서 공유하는
요청은 유지합니다. 늦게 도착한 결과가 실패·취소 상태를 덮어쓰지 않도록 검사합니다.
13개 신규 회귀 검사는 요청 순서, 부분 완료 차단, 각 문서의 실패·버전·스키마 오류와
취소를 확인합니다. 이 변경은 다운로드 의존성을 줄이는 것이며, 위 배포의 첫 준비
측정값을 새 코드의 성능으로 재사용하거나 실제 향상 배율로 환산하지 않습니다.
