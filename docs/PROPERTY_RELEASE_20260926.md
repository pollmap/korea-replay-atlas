# 과거 거래 확대와 동일 조건 비교

후보 자료: `property-54bf1817fdcc7bd9`. 원본 해시·페이지·정규화 결과를
다시 검증해 기존 공개 1,843,263건에서 2,108,860건으로 265,597건을 추가했다.
단지 식별 항목은 42,737개이며 이것이 검증된 좌표 수를 뜻하지는 않는다.

## 실제 확보 상태

- 현재 코드 기준 256지역 × 121개월 × 매매/전월세 = 61,952개 작업.
- 완료 8,077, 정상 빈 결과 288, 실패 1, 대기 53,586.
- 2016.09·2016.10은 각 512작업을 확인했다. 2016.11은 2작업만 확인했다.
- 2025.06 26작업, 2025.07 146작업, 2025.08 511작업이다.
- 2025.09–2026.09는 월별 512작업이며 2026.09는 진행 중 계약월 잠정 자료다.
- 행정구역 개편의 과거 효력 코드 대조는 미완료다. 현재 코드 조회 성공을
  당시 전국 모든 거래의 누락 없는 확보로 해석하지 않는다.
- 2016–2026 기간의 중간 대부분은 아직 비어 있다. **연속 10년 수집 완료가 아니다.**

## 화면과 계약

기존 122 partition 상한 때문에 10년 자료를 열지 못하던 오류를 수정했다.
상세와 비교는 같은 기간·전용면적·거래 유형을 사용하고, 비교는 모든 선택
지역이 공통으로 확인된 월만 계산한다. 미게시·수집 실패·다운로드 한도를
구분하며, 기간 앞뒤 이동 및 오류 재시도를 제공한다.

지도 848개 단지 연결과 842개 기본정보는 새 거래 release에 대해 다시 생성했다.
도로명주소·건물번호·명칭의 일대일 연결 기준은 유지했다. 공급자 좌표의
정확성 검증 완료를 주장하지 않는다. 이전 release 자료와 공유 배포는 보존한다.
3D 코드와 원본 자료는 변경하지 않았다.

## 정기 운영

표준 무료 GitHub Actions에서 private D1 head 복원 → 제한 수집 → 원본 보존
→ 재검증 후 head 갱신을 실행하는 workflow를 추가했다. 최근 정정과 과거
자료 수집을 교대로 처리하며, 일시 실패만 제한적으로 재시도한다.

전용 Cloudflare 인증과 첫 원격 실행 검증 전에는 스케줄 활성화를 하지 않는다.
정기 수집과 공개 사이트 자동 게시를 별도로 판정한다. 이 릴리스만으로
노트북 없이 계속 공개 갱신되는 전체 운영 완료를 주장하지 않는다.
