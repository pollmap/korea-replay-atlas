# KOREA REPLAY 브랜드 기준

**제품 약속:** 공식 아파트 실거래와 지역 자료를 전국 지도에서 읽고 비교한다. 3D 도시·교통·시간 기록은 같은 위치를 더 깊이 살펴보는 기능으로 유지한다.

## 표식과 이름

로고는 기존 이름의 `K`를 하나의 연속된 경로처럼 그린 원본 벡터다. 흰색 세로획과 위쪽 경로는 지도의 안정적인 좌표축, 민트색 아래쪽 경로는 선택한 장소에서 이어지는 탐색을 뜻한다. 작은 지도 핀·집 지붕이나 참고 서비스의 로고를 차용하지 않는다. 앱 헤더와 브라우저 아이콘은 같은 경로를 사용한다.

- 이름: `KOREA REPLAY`를 유지한다. 서비스 설명은 `전국 아파트 실거래 지도`로 명확히 쓴다.
- 주색: 짙은 남색 `#142e55`(로고 배경·문서 표제), 파랑 `#2563eb`(주요 조작), 민트 `#72e0c6`(로고의 탐색 경로).
- 데이터 상태 색은 브랜드 색과 별개로 정의한다. 실거래 ID가 연결된 서울시 후보 점의 녹색은 **위치 확정**을 의미하지 않는다.
- 수치 표기에는 가격, 면적, 계약일과 취소 상태를 붙인다. 최근 한 거래를 단지 시세나 모든 면적의 대표 가격으로 표현하지 않는다.

## 화면 사용 규칙

지도는 항상 주 작업면이다. 데스크톱에서는 탐색·상세를 한 좌측 패널 안에서 전환하고, 모바일에서는 접힘·중간·전체 하단 패널을 사용한다. 단지 선택 직후 첫 화면에서 단지명, 거래 유형, 최근 실거래 가격·면적·계약일을 볼 수 있어야 한다. 출처와 좌표 품질은 상세에서 접근할 수 있게 두되, 지도 위에서 선택한 점을 가리는 중복 안내는 숨긴다.

호갱노노와 아실에서 관찰한 지도 중심 탐색, 가격 표식, 빠른 거래 필터, 단지 상세 진입의 **사용 흐름**을 참고한다. 화면 이미지, 아이콘, 색 배합, 전용 데이터와 문구를 그대로 복제하지 않는다. 실제 구현·자료 권한·검증 상태는 [화면 흐름 감사](PROPTECH_UX_AUDIT_20260923.md)에서 따로 추적한다.
