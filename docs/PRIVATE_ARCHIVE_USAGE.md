# 비공개 수집 저장소 사용량 기록

2026-09-28. 서버 수집 결과의 `archive_io`는 동일 archive client가 수행한 복원·원문 저장·snapshot·체크포인트·lease 정리 요청을 집계한다. 성공뿐 아니라 공간 부족에 따른 일시 중단과 오류 결과에도 포함한다. CLI가 `run_automation`의 종료와 정리를 기다린 뒤 기록하므로 마지막 정리 요청이 빠지지 않는다. 인증 전에 실패하면 `available:false`이며 사용량을 0으로 생성하지 않는다.

이는 **한 client 실행의 관측치**다. 계정 전체 사용량, 다른 실행의 비용, 무료 요금제 확인, 공간 예약, 전체 20년 자료의 저장 가능성 또는 공개 배포 완료를 뜻하지 않는다. 기존 원본·head·XZ/legacy 복원 계약, 호출 예산, Broker SQL 허용 목록과 무료 표준 runner를 유지한다. 자동 재시도·원본 삭제·저장소 증설·요금제 변경은 추가하지 않는다.

## 기록 계약

| 필드 | 의미와 한계 |
|---|---|
| `query_calls` / `transport_attempts` | client 진입 / 실제 전송을 시도한 횟수. SQL 허용 목록 거부 등 로컬 실패는 전송 횟수에 포함하지 않는다. |
| `outcomes` | 성공, 로컬 거부, 명시적 원격 오류, 응답 미확정. 실패를 성공 또는 미사용으로 바꾸지 않는다. |
| `mutating_attempts` / `writes_unconfirmed` | 쓰기가 가능한 요청 / 성공을 확인하지 못한 쓰기 시도. 전송 후 연결이 끊겨도 기록하며, 재전송하지 않는다. 복수 SQL 문장과 판별이 모호한 문장은 보수적으로 쓰기 가능으로 분류한다. |
| `request_body_bytes_attempted` / `response_body_bytes_observed` | 전송 시도한 JSON 본문 / 실제 읽은 응답 본문. 네트워크 헤더·TLS·재전송 비용이나 DB 저장량이 아니다. |
| `rows_read` / `rows_written` | D1이 반환한 유효한 정수 메타의 합 `observed`. 미제공·잘못된 메타는 `missing_results`, 미확정 응답은 `unverified_queries`로 구분한다. 하나라도 있으면 `total:null`, `complete:false`이다. 실제 0은 보존한다. `changes`를 쓰기 과금 행 수로 대신하지 않는다. |
| `database_sizes` | 고정 별칭 control/object0~3별 첫·마지막·최대 `size_after`, 관측 횟수·증감. 원문·파생물별 저장 비용으로 해석하지 않는다. 크기 감소도 그대로 기록한다. |

직접 D1 REST의 복수 결과는 전부 합산하며 기존 호출자에게 반환하는 첫 결과는 그대로다. Broker 응답도 같은 집계기를 쓴다. 오류 응답에서 확보한 메타는 보존하되 확정 총량으로 승격하지 않는다. 객체나 SQL마다 목록을 쌓지 않고 고정 크기 카운터만 유지한다. SQL·매개변수·원문·인증정보·실제 DB ID·계정 ID·호스트·상세 오류 문구는 보고서에 넣지 않는다.

크기 관측의 `first_observation_precedes_mutations`가 false면 첫 수치부터 이미 쓰기 후일 수 있다. `last_observation_covers_mutations`는 마지막 쓰기 시도 이후의 크기 관측이 있는지만 나타낸다. 불확실한 쓰기 뒤 다시 크기를 읽었어도 해당 쓰기 결과나 과금은 확정되지 않으며 `writes_unconfirmed`와 `total:null`은 유지한다. 동일 계정의 다른 작성기가 있을 수 있어 단순 전후 차이는 이 실행의 인과적 저장 비용이 아니다.

## 현재 저장·확보 기준선

2026-09-28 09:29 KST 읽기 전용 감사에서 지정 지역은 **4,270 / 48,160 가용 작업**(8.87%)이었다. 원천 제공 전 5,824작업은 별도다. 공개 `property-87d1c67336e97209` 이후 신규 259작업·131,092원천행과 기존 95작업의 갱신이 미게시 상태다. 전체 240완료개월·당월 잠정 자료의 확보 완료가 아니다.

같은 감사에서 객체 DB 4개의 합은 694,956,032B, 계정의 DB 6개 합은 733,999,104B였다. 다음 100회·64MiB 원문 예산은 기존 사전검사를 통과했으나 파생물·정정 누적과 전체 20년 보관 가능성을 보장하지 않는다. 계정 구독 조회는 권한 거부로 현재 요금제 확인이 미완료였다. 요금제·무료 총량 확인과 장기 보관 구조 검증은 별도 조건이다.

## 검증과 운영

회귀 검사는 두 실제 transport 경로의 메타, 유효한 0, 미제공·음수·문자·불리언, 복수 결과, HTTP 오류·인코딩·응답 제한, commit 후 응답 유실, 허용 목록 거부, SQLite를 이용한 전체 복원·수집·체크포인트 흐름, CLI 실패·정리와 비밀정보 canary를 포함한다. 코드 검증과 실제 서버 실행을 별도로 기록한다.

병합 후 기존 예약 workflow는 새 코드를 사용한다. 검증을 위해 수동 실행이 필요하면 먼저 실행 중인 작업과 lease를 확인하며 한 번만 실행한다. 서버 수집기만 바뀌므로 대용량 Pages 자산은 재업로드하지 않고 대표 runtime·기존 공유·404를 확인한다. 원본을 다시 읽고 SHA·정규화·기존 ID 감사를 통과한 새 데이터 후보만 게시할 수 있다.
