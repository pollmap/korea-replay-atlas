# 단지 기본정보와 내 검색조건

2026-09-25 구현. 기존 2D 아파트 탐색에 추가하며 3D 렌더러·지도 원본·공개 거래 릴리스를 변경하지 않습니다.

## 단지 정보

- 서울시 공동주택 아파트 정보의 2026-09-23 수집본을 사용합니다. 기존 고유 도로명주소·이름 연결 장부와 일치하는 활성 아파트·주상복합 842개 단지입니다. 전국 또는 서울의 모든 단지 확보를 의미하지 않습니다.
- 세대수, 동 수, 주차대수, 세대당 주차, 도로명주소, 사용승인일, 난방, 복도 유형, 시공사, 관리 방식을 표시합니다. 관리비는 이 자료에 없으므로 추가하지 않습니다.
- 국토부 단지 ID와 서울시 K-apt ID는 별도로 유지합니다. 단지 좌표 검증 상태를 바꾸지 않습니다. 다른 부동산 릴리스에는 현재 연결 자료를 적용하지 않습니다.
- 원본 페이지 해시 검증 → 기존 연결 장부 검증 → 공개 항목 선별 → 타입/날짜/중복 검증 → 결정론적 JSON 순서입니다. 전화·팩스·홈페이지·좌표를 게시하지 않습니다.
- 원천이 없는 값은 `자료 없음`으로 유지합니다. 주차 0대는 제공된 0으로 표시하며 세대수가 없거나 0이면 세대당 주차를 계산하지 않습니다.
- 공식 출처와 공공누리 제1유형 조건은 `THIRD_PARTY_NOTICES.md` 및 화면의 출처·기준일에서 확인합니다.

## 내 검색조건

- 지역·거래 유형별 검색어, 법정동, 가격, 전용면적, 건축연도, 정렬, 거래 유무 조건을 기기 내 저장합니다. 계약월은 복원 시 현재 선택을 유지합니다.
- 최대 50개, JSON 가져오기·전체 내보내기를 제공합니다. 가져온 파일은 크기·스키마·범위·식별자 검사를 통과해야 반영됩니다. 같은 ID의 기존 항목은 덮어쓰지 않습니다.
- 잘못된 파일·저장 공간 오류가 있으면 기존 저장 자료를 유지하고 오류를 표시합니다. 다른 탭의 변경도 반영합니다. 매매 조건이 전월세 보증금 필터로 묵시적으로 재사용되지 않습니다.
- 계정 간 동기화나 서버 저장 기능은 아닙니다. 사이트 데이터 삭제 시 사라질 수 있으므로 내보낸 파일로 복구합니다.

## 확인 항목

- 헬리오시티: 공식 원천의 9,510세대·84동·주차 12,096대·사용승인 2018-12-28와 화면 값 대조.
- 잘못된 날짜/중복 식별자/문자형 숫자/가격 역전/과대 파일 및 저장 개수 제한 회귀 검사.
- 실제 브라우저에서 조건 저장 → 초기화 → 복원 → 재방문 → 복원, 매매/전월세 분리 확인.
- 390×844 모바일에서 단지 기본정보를 확인하며 기존 설명 목록의 중첩 grid 충돌을 수정.
- 전체 웹 테스트 917개 중 한 배포 파일 테스트가 병렬 빌드 중 5초 제한 초과. 해당 파일과 변경 테스트를 단독 재실행해 20개 통과. CI의 전체 재실행을 별도로 확인합니다.

## 과거 자료 수집 상태

2026-09-25 공식 API 21회 응답을 원격 원본 저장소에 추가 보존했습니다. 확인된 장부는 수집 완료 8,077, 빈 응답 확인 288, 실패 1, 대기 53,586개입니다. 대상 지역·월·유형 작업 총 61,952개이며 수집 완료에는 부분 전국 기간이 포함됩니다. 두 번째 수집은 무료 원격 저장소의 일일 쓰기 제한으로 중단됐습니다. 원본과 체크포인트는 보존하며 공개 거래 릴리스에는 아직 반영하지 않았습니다. 전국 10년 이력 완료·자동 정기 게시 완료를 뜻하지 않습니다.
