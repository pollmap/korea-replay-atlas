# 전국 2D·부동산 확장 구현 기록

검증일: 2026-09-20 KST. 기존 전국 3D 코드·원본·공개 Worker를 보존하며 같은 프로젝트를 확장합니다.

## 사용 흐름

전국 지역 거래량 → 시군구 → 계약월·매매/전월세 → 국토부 식별 단지 → 전용면적 → 거래 점·원문 표·CSV. 지역은 최대 3개를 같은 완료 계약월로 비교합니다. 단지는 최대 3개를 선택한 같은 계약월·거래유형·정확히 같은 전용면적으로 비교하며, 표본 0건과 미수집을 구분합니다. 중앙값은 공식 가격지수나 현재 호가가 아닙니다.

2D와 3D는 동시 생성하지 않습니다. 전환할 때 현재 지도 중심을 전달하며, 시간·선택 상태를 유지합니다. 거리·면적 측정은 구면 근사치로 측량이나 지적 면적이 아닙니다. 즐겨찾기는 기기 내 최대 100개이며 JSON 가져오기·내보내기를 제공합니다. 위치 조회는 사용자가 버튼을 누른 경우에만 요청합니다.

## 데이터 정확성

- 조회 성공, 모든 페이지 수집, 전국 월별 수집 완료를 별도 기록합니다. 실패·대기는 `null`이며 거래 0건으로 바꾸지 않습니다.
- 공식 단지 일련번호는 행정구역 개편 전 접두어를 보존할 수 있습니다. ID 앞자리를 현재 시군구로 추론하지 않습니다.
- 공식 좌표 연결 전에는 지도에 단지 위치를 만들지 않습니다. 이름이 같은 단지를 서로 합치지 않습니다.
- 취소 기록과 원문 식별자·수집시각·SHA를 보존합니다. 매매의 취소·취소 여부 미확인은 기본 통계에서 제외합니다. 전월세 원천은 취소 상태를 제공하지 않습니다.
- 2025년 SGIS 경계와 2026년 현행 코드/인구표를 코드 접두어나 이름만으로 결합하지 않습니다.

## 배포와 복구

새 앱은 `korea-replay.pages.dev`, 새 데이터는 별도 `korea-replay-data.pages.dev` 프로젝트를 사용합니다. 후보 데이터의 실제 불변 Pages URL과 manifest SHA를 앱에 고정합니다. 앱과 데이터는 원자적인 하나의 릴리스 참조로 복구하며 없는 공유 버전을 최신 버전으로 대체하지 않습니다. `/api/v1/live/*`만 기존 Worker 서비스 바인딩을 사용하고 나머지 정적 자료는 직접 제공됩니다.

각 프로젝트 20,000개 파일·25MiB 파일 제한을 검사합니다. 2D 묶음은 1MiB 제한을 별도 적용합니다. R2·유료 러너·도메인 구입·과금 플랜은 사용하지 않습니다. Pages 원격 작업은 Wrangler의 자동 Workers 위임을 피하도록 [REST 전용 절차](PAGES_DEPLOYMENT.md)를 사용합니다.

소스 Git 보관은 원본 데이터 백업이 아닙니다. `.local/raw`, 정규화 중간물, 인증 파일과 복구 증빙은 공개 저장소에서 제외합니다. 기존 로컬 프로젝트·원본은 삭제하지 않습니다.

## 성능 측정 원칙

10배와 2초는 목표입니다. 2D 진입 시 Cesium·GLB·지형 다운로드가 없는지 별도로 확인합니다. DPR 상한 1.5로 바뀌므로 이전 3D와 비교할 때 해상도 차이를 명시해야 합니다. 지도 준비·자료 표시·프레임·메모리를 분리하고, 대량 배치가 동시에 실행 중인 측정은 전용 Radeon 860M 최종 기준 측정으로 승격하지 않습니다.
