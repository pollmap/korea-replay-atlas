# 실거래 이력과 민간 데이터 재사용 확인

확인일: 2026-09-27. 공식 웹 문서의 열람·검색만 수행했습니다. 거래 API 호출, 로그인, 대량 크롤링, 우회, 결제는 하지 않았습니다. 이 문서는 수집 가능성 및 조건의 조사이며 실제 데이터 확보·전국 완료 증명이 아닙니다.

## 공식 실거래: 확보할 수 있는 기간

현행 [국토교통부 공개안내](https://rt.molit.go.kr/pt/info/info.do?mobileAt=)는 매매 2006년 1월 이후, 전월세 2011년 1월 이후를 공개 대상으로 안내합니다. 안내 본문은 이미지로 제공되어 이번 웹 텍스트 추출에는 날짜가 나오지 않았으며, 같은 작업의 주 에이전트가 원문 화면에서 날짜와 대량 이용 시 API 사용 안내를 확인했습니다. [서울시 오피스텔 거래 화면](https://land.seoul.go.kr/land/rtms/rtmsOfficetel.do)에서도 매매 2006년 이후·전월세 2011년 이후라는 현재 안내를 직접 확인했습니다.

| 유형 | 수집 하한으로 채택할 기준 | 이번 조사에서 확인하지 않은 것 |
|---|---|---|
| 아파트 매매 | 2006-01 | 모든 지역·월의 실제 응답과 페이지 완전성 |
| 아파트 전월세 | 2011-01 | 2011년 이전 개별 자료의 존재 여부; 20년 연속 이력 |
| 오피스텔 매매 | 2006-01 | 모든 지역·월의 실제 응답과 페이지 완전성 |
| 오피스텔 전월세 | 현행 안내에 맞춰 2011-01 | 2006~2010년 API 제공 여부; 아래 과거 보도 표현의 정확한 적용 범위 |

현재 완료 계약월을 2026-08로 삼으면 매매 2006-09~2026-08은 240개월이고, 공식 공개 하한부터는 248개월입니다. 전월세 2011-01~2026-08은 188개월입니다. 따라서 네 유형 모두에 20년치가 존재한다고 표시할 수 없습니다. 공개 하한은 수집 대상 설정의 근거이며 각 구역·월을 실제로 수집했다는 뜻은 아닙니다.

[국토부의 2015-09-15 정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148800734)은 2015-09-17에 오피스텔 공개를 시작하면서 2006년 이후 매매·전월세 약 39만 건을 공개한다고 합쳐 표현했습니다. 이는 서비스 공개 개시일과 거래 대상기간이 다르다는 근거이지만, 전월세만의 2006년 시작을 분리해 설명하지 않습니다. 현행 안내의 2011년 전월세 하한과 차이가 있으므로 과거 문장만으로 2006~2010년 오피스텔 전월세가 현재 API에서 제공된다고 확정하지 않습니다. 실제 인증 응답 또는 기관 확인이 있어야 별도 범위를 확장합니다.

## 공식 API 조건

아래 네 상세 페이지 원문을 직접 확인했습니다. 모두 비용은 무료, 라이선스 표시는 **“이용허락범위 제한 없음”**, 개발·운영 단계는 자동승인, 개발계정 신청 가능 트래픽은 10,000으로 표시됩니다. 운영계정은 활용사례 등록 후 증설 신청 경로가 있습니다. 실제 계정 승인·기간·일일 및 초당 한도는 해당 계정과 API 응답을 별도로 확인해야 합니다.

| 서비스 | 공식 상세 페이지 | 문서 갱신일 |
|---|---|---|
| 아파트 매매 신고상세 (실제 수집 원천) | [15126468](https://www.data.go.kr/data/15126468/openapi.do) | 2026-09-08 |
| 아파트 전월세 | [15126474](https://www.data.go.kr/data/15126474/openapi.do) | 2026-07-29 |
| 오피스텔 매매 | [15126464](https://www.data.go.kr/data/15126464/openapi.do) | 2026-07-22 |
| 오피스텔 전월세 | [15126475](https://www.data.go.kr/data/15126475/openapi.do) | 2026-07-22 |

네 API 모두 법정동 코드 앞 5자리와 계약년월 6자리로 조회합니다. 상세 페이지의 시간범위는 비어 있고 등록일은 2024-01-25이므로, **API 등록일을 거래 이력 시작일로 사용하면 안 됩니다.** 매매 신고자료와 전월세 신고·확정일자 자료의 범위를 구분해야 합니다. 비공개 동·호 또는 개인정보를 민간 정보와 결합해 복원하지 않습니다.

수집·정규화·자체 통계·서비스 게시의 우선 원천은 이 공식 API입니다. 원문 출처, 조회 계약월, 수집시각, 취소/정정과 요청 성공 여부를 유지하고 페이지 누락 및 실패를 거래 0건으로 처리하지 않습니다. 공식 실거래 공개자료를 거래량의 공식 승인통계와 혼동하지 않습니다. 서울시 화면도 거래통계 외부 공개 시 신고일 기준 공식 통계를 이용하도록 안내합니다.

## 민간 서비스: 접근과 재사용은 별도

사용자가 크롤링을 허용한 것은 작업 수행에 대한 사용자 승인입니다. 해당 사이트·콘텐츠 권리자의 재배포 허락까지 확인한 것으로 간주하지 않습니다. 공공 원자료를 민간 사이트에서 다시 가져오기보다 공식 API에서 확보하면 민간 가공물·정렬·매물·사진·후기를 섞는 문제를 줄일 수 있습니다.

### 아실

[공식 이용약관 원문](https://asil.kr/rts_m/contents/agree_user.html)을 직접 확인했습니다. 제19조는 지적재산권 침해 및 서비스 방해를 제한하고, 제20조 2항은 회사에 권리가 있는 정보를 사전 승낙 없이 영리 목적으로 복제·송신·배포하거나 제3자가 이용하게 하는 행위를 제한합니다. 이 페이지는 2018-05-01 적용으로 표시됩니다. 현재 모든 웹·앱 기능에 적용되는 최신 일반 약관인지까지는 확인하지 못했습니다. 별도 인테리어 파트너의 2026년 약관을 일반 이용자 약관으로 대신하지 않았습니다.

원문에서 민간 가공 데이터의 공개 재배포 허용이나 데이터 수집용 공개 API 권한은 확인하지 못했습니다. 사이트에 표시되는 국토부 거래는 공식 API에서 직접 수집할 수 있지만, 아실 고유의 공급 정리·매물 집계·사진 등은 별도 원천과 이용조건을 확보한 항목만 자체 구현에 사용할 수 있습니다.

### 호갱노노

정확한 일반 약관 주소는 [https://hogangnono.com/privacy](https://hogangnono.com/privacy)입니다. 검색 인덱스에는 버전 12, 2025-09-22 시행으로 표시되며 실거래는 국토부 공개자료를 기반으로 하고 다른 자료는 가공해 제공한다고 안내합니다. **직접 원문 열기는 HTTP 403으로 실패했습니다.** 이 인덱스 내용은 최신 원문 검증으로 승격하지 않습니다. 현재 자동 수집·공개 재배포 허락 여부는 미확인입니다. 위치정보 약관이나 개인정보처리방침을 데이터 라이선스 대신 사용하지 않았습니다.

호갱노노의 후기·사진·개별 가공 통계를 가져와 재게시할 수 있다는 근거를 확보하지 못했습니다. 공개 화면의 기능 관찰과 자체 UX 구현, 공식 원천에서 같은 종류의 통계를 직접 계산하는 작업을 데이터 복제와 구분합니다.

### 네이버 부동산

[네이버 이용약관](https://policy.naver.com/policy/service.html)의 현재 페이지는 2025-07-10 적용으로 표시됩니다. 타인 콘텐츠를 이용해도 그 권리를 취득하는 것이 아니라는 점과 허락 없는 자동 수집·남용 방지 조치 무력화 등을 제한하는 내용을 직접 확인했습니다.

[공식 법적고지](https://policy.naver.com/policy/disclaimer.html)는 자동 접속·정보 수집의 예외를 명시적 허락, 정식 API와 그 약관 준수, 개발자 가이드·robots가 허용하는 탐색 범위로 설명합니다. [검색결과 수집 정책](https://policy.naver.com/policy/search_policy.html)도 공개 열람과 복제 허가를 구분합니다. 네이버 지도 API의 사용 권한을 네이버 부동산 매물 데이터의 수집·재게시 권한으로 확대하지 않습니다. 이번 조사에서 부동산 매물 전체를 공개 서비스로 재배포할 수 있는 무료 권한은 확인하지 못했습니다.

읽기 실패는 robots 부재·수집 허용·특정 Disallow 규칙의 증거가 아닙니다. IP 전환, 로그인 세션 차용, 보안문자 우회 등으로 재시도하지 않았습니다. robots의 탐색 허용 여부를 확인하더라도 데이터의 저장·변경·공개 재배포 라이선스는 별도로 확인해야 합니다.

## 현재 채택할 수 있는 것

- 공식 네 실거래 API: 무료·제한 없음 표시는 확인했습니다. 승인된 호출 예산 안에서 과거 지역·월을 수집하고 실제 응답을 검증할 수 있습니다. 이번 조사 자체에서 과거 거래를 새로 확보한 것은 아닙니다.
- 현행 안내에 없는 전월세 2006~2010: 수집 완료나 거래 0건으로 표시하지 않습니다. 공개 지원 범위 미확인으로 남깁니다.
- 민간 서비스: 화면·기능을 관찰해 사용자 흐름을 개선할 수 있으나, 민간 DB를 대량 추출해 우리 공개 DB로 게시할 권한은 확보하지 못했습니다. 데이터별 정식 제공 조건 확인이 선행돼야 합니다.
- 문서 확인, 계정 승인, API 응답 성공, 지역·월 전체 확보, 공개 게시 완료를 각각 독립 상태로 관리합니다.
