# 단지 목록과 제공 위치 연결

2026-09-24. 서울시 제공 점과 실거래 ID가 연결된 기존 848개 단지를 대상으로, 목록 → 지도 → 상세의 이동을 연결했습니다. 단지별 좌표 정확성을 새로 검증하거나 전국 좌표를 확보한 작업은 아닙니다.

## 동작

- 목록에서 연결된 단지를 선택하면 같은 실거래 상세를 열고 제공 점으로 이동합니다. 선택 표시를 함께 갱신합니다.
- 공유 링크로 연 상세에는 `지도에서 제공 위치 보기` 버튼이 나타납니다. 버튼을 누르기 전에는 공유된 카메라를 단지 점으로 강제 이동하지 않습니다.
- 목록 복귀·다른 단지 선택·자료 릴리스 변경 때 이전 선택 표시를 해제합니다. 검색 조건은 기존 목록 유지 동작을 따릅니다.
- 미연결 단지는 기존 지역 지도를 유지합니다. 다른 릴리스의 단지 ID에 과거 좌표를 자동 재사용하지 않습니다.
- 위치 자료 요청 실패는 거래 조회를 막지 않으며 별도 재시도 버튼을 제공합니다. 해시·크기·중복·좌표 범위·원천 및 릴리스가 다르면 위치 연결을 거부합니다.

## 자료와 성능 경계

`scripts/build-property-map-index.mjs`는 이미 공개한 `seoul-kapt-points-b63b62af834062de.geojson`을 해시로 고정하고 848개의 단지 ID·K-apt ID·경위도만 추출합니다. 생성한 `src/data/seoul-property-navigation.json`은 55,929 bytes이며 원본 좌표와 모두 일치하는지 테스트합니다. 전체 점 자료는 1,119,536 bytes입니다. 탐색 색인은 해당 부동산 릴리스의 서울 단지를 선택했을 때만 공용 다운로드 큐를 통해 한 번 받습니다. 원천 지도 점 레이어 자체의 다운로드량 감소나 지도 속도 개선 배율을 의미하지 않습니다.

대상 부동산 릴리스는 `property-eea48453a819f517`입니다. 별도 릴리스로 갱신할 때는 ID 연결과 원천을 다시 검증하고 색인을 재생성해야 합니다. 생성기는 기존 GeoJSON을 덮어쓰지 않습니다.

원천은 [서울시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/A/1/datasetView.do), 공공누리 제1유형입니다. 실제 원천 설명은 좌표 X/Y이며 좌표계·대표점의 의미는 확인되지 않았습니다. 따라서 `provider_xy_crs_unconfirmed` 상태를 유지합니다. 유일한 도로명주소·단지명에 따른 실거래 ID 연결과 좌표 정확성은 구분하며, `PropertyComplex.position`을 검증된 값으로 채우지 않습니다. 화면에도 `서울시 제공 점 · 위치 검증 중`을 표시합니다.

## 검증

- 848개 색인 항목을 원본 GeoJSON의 ID·좌표·K-apt ID와 전수 비교했습니다.
- 중복 ID·중복 K-apt·좌표 범위 이탈·릴리스 불일치·출처 해시 변경·검증 상태 임의 승격을 거부합니다.
- 미지원 지역/릴리스에서 요청하지 않는 동작, 동시 선택 요청 공유, 바이트 변조 거부, 실패 후 재시도를 테스트했습니다.
- 프로덕션 빌드와 기존 불변 공개 데이터로 헬리오시티 상세 → 제공 위치 보기, 목록 복귀 시 표시 해제, 목록 검색 → 단지 선택 시 자동 이동을 확인했습니다.
- 웹 테스트 881개, 타입검사·린트·빌드가 통과했습니다. 모바일 시각 검수, 전국 좌표 확보와 10년 거래 수집 완료를 뜻하지 않습니다.
