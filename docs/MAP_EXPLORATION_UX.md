# 지역 선택 중심의 2D 아파트 지도

시도·시군구 선택과 실제 표시 경계를 연결합니다. 구를 선택하면 해당 구의 음영·외곽선과 소속 행정동을 표시하고, 지도 또는 행정동 선택기로 동의 범위를 강조합니다. 행정동은 거래 목록의 법정동 필터와 별개입니다. 현재 경계는 SGIS 2025-06-30 기준이며, 정확히 연결되지 않는 지역명은 다른 지역으로 대체하지 않습니다.

경계는 선택한 지역의 파일만 요청합니다. 파일 크기·SHA를 검증하고, 진행 중 선택이 바뀌면 취소합니다. 새 자료가 준비되기 전까지 이전 경계는 유지하며, 늦게 도착한 이전 응답이 새 선택을 덮어쓰지 않습니다. 경계 파일도 지도의 공통 네 개 다운로드 슬롯을 사용합니다. 4MiB 원문 캐시는 지도 해제 시 비웁니다.

시도 선택은 제목·거래량·목록을 같은 범위로 맞추고 URL의 `regionQuery`로 보존합니다. 선택 지역과 단지 변경은 브라우저 이력으로 되돌릴 수 있으며, 3D는 더보기 메뉴에서 별도로 진입합니다. 아파트 기본 화면에서는 2D/3D·전국·지역 분석·경계·레이어 버튼 묶음을 제거하고, 닫은 목록은 ‘아파트 목록’으로 다시 엽니다. 3D 렌더러와 원본 데이터는 변경하지 않습니다.

서울·인천 상세 지도의 넓은 확대 범위는 별도 데이터 릴리스를 필요로 합니다. 건물은 고정 네 개 파티션을 사용해 zoom 12~13에서 표시하고, zoom 14부터 기존 상세 모델로 이어집니다. 상세 건물이 아직 로딩 중이면 개략 건물 레이어를 유지합니다. 상세 도로는 zoom 13부터, 기존 전국 도로는 zoom 6부터 표시합니다. 범위·원본 ID·크기 감사는 `MAP_DETAIL_OVERVIEW.md`를 참고합니다.

노선 대표색은 원본 관계로 식별한 서울 1~8호선에 적용합니다. 번호만 같은 타도시 노선이나 일반 철도에 서울 색상을 추정하지 않습니다. `MAP2D_RAIL_COLORS.md`에 식별 근거와 한계가 있습니다.

이 변경은 법정동 경계 확보, 전국 상세 건물 완전성, 출퇴근 시간 자체 계산, 10년 거래의 공개 수집 완료를 의미하지 않습니다. GPU 성능은 실제 공개 환경의 측정 결과와 별도로 판단합니다.
