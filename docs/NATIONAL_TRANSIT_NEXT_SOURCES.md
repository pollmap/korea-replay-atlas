# 전국 철도 연결의 다음 원천과 실시간 공백

확인일: **2026-09-20 KST**. 저장소 코드와 제공기관의 공개 명세만 조사했습니다. 인증키·계정 승인 화면을 읽지 않았고, 실제 데이터 API 호출·활용신청·배포는 하지 않았습니다.

**다음 구현은 KORAIL 정식 API의 전일 실제 역 도착·출발 기록을 권장합니다.** 기존 한 역·한 날짜의 공개 샘플을 날짜·역을 선택하는 정식 수집 경로로 바꾸는 구체적인 공백입니다. 과거 기록 재생을 넓히는 작업이며, 현재 열차 위치 기능의 완성으로 계산하지 않습니다.

부산·대구·광주·대전·인천에서 이번에 확인한 공식 자료 중에는 **재사용 가능한 무료 실시간 열차 상태 API의 현재 계약을 확정한 것이 없습니다.** 아래 시간표·표준 소요시간과 실시간 화면을 현재 GPS 또는 현재 역 상태로 대신 연결하지 않습니다. 이는 조사 범위의 미확인이며, 해당 기관에 어떤 실시간 시스템도 없다는 뜻은 아닙니다.

## 연결 우선순위 1: KORAIL 정식 과거 운행 기록

[한국철도공사 열차운행정보 15125762](https://www.data.go.kr/data/15125762/openapi.do)는 여객열차의 실제 역 기록을 **3개월 전부터 전날까지** 제공합니다. 계획 자료와 별개이며 현재 GPS는 아닙니다. 무료·이용허락 제한 없음, 개발·운영 자동승인, 개발 **10,000회/일**, 운영 증설은 활용사례를 통한 신청 대상입니다. 해당 서비스의 이 계정 승인은 미확인입니다.

공식 페이지의 내장 Swagger에서 확인한 계약은 다음과 같습니다. 기술 필드만 추출했으며 인증 호출로 검증한 응답은 아닙니다.

```text
Base: https://apis.data.go.kr/B551457/run/v2
GET /travelerTrainRunInfo2
  serviceKey
  pageNo, numOfRows, returnType
  cond[run_ymd::GTE], cond[run_ymd::LTE]
  cond[stn_cd::EQ], cond[stn_nm::EQ]
  cond[mrnt_cd::EQ], cond[mrnt_nm::EQ]
GET /codes2
  serviceKey, cond[type::EQ]
  pageNo, numOfRows, returnType
  cond[code::EQ], cond[value::LIKE]
```

| 부분 | 공식 명세의 필드 |
|---|---|
| 결과 | `response.header.resultCode/resultMsg`, `response.body.dataType/numOfRows/pageNo/totalCount` |
| 행 | `response.body.items.item[]` |
| 식별 | `run_ymd`, `trn_no`, `trn_run_sn`, `stn_cd/stn_nm`, `mrnt_cd/mrnt_nm` |
| 상태·실제 시각 | `uppln_dn_se_cd`, `stop_se_cd/stop_se_nm`, `trn_arvl_dt`, `trn_dptre_dt` |
| 코드 조회 | `type/code/value`; 유형 `stn_cd`, `mrnt_cd`, `stop_se_cd`, `uppln_dn_se_cd` |
| 별도 계획 API | `/travelerTrainRunPlan2`: `trn_plan_dptre_dt`, `trn_plan_arvl_dt` |

포털의 오류 안내는 `20` 접근권한/키 누락, `30` 키 미등록, `31` 만료, `22` 일일 한도, `23` 초당 한도, `10` 인자 오류, `12` API 부재, `29` IP 차단, `01/04/05` 내부·HTTP·연결 지연을 구분합니다. 성공 HTTP만으로 정상 자료로 판정하지 않습니다. [공식 명세·오류표](https://www.data.go.kr/data/15125762/openapi.do)

### 제안하는 파서와 실행 경계

다음은 **구현안**이며 아직 구현·실조회한 기능이 아닙니다.

- 열차번호는 선행 0을 보존하는 문자열로 다룹니다. `(run_ymd, trn_no, trn_run_sn, stn_cd)` 후보 키를 먼저 감사하고, 상충하는 동일 키를 조용히 합치지 않습니다.
- 실제 날짜·시각의 KST 해석과 자정 경계를 검증합니다. 도착/출발 결측을 0시로 채우지 않습니다. 계획 시각으로 실제 결측을 채우지 않습니다. 원천 이벤트·조회 시각을 분리합니다.
- 실제 승인 후 응답에서 성공 코드, 날짜 형식, 단일 행/목록 형태, 빈 결과 구조를 확정합니다. 정상 성공과 `totalCount=0`의 일관성이 확인된 경우에만 빈 자료로 분류합니다. XML 게이트웨이 오류·인증 거부·페이지 누락은 빈 운행으로 바꾸지 않습니다.
- 페이지별 총수와 중복·누락을 검사하고 완료 전 게시하지 않습니다. `stn_cd`를 지도 역에 연결할 때 출처와 연결 확신을 기록하며, 역 좌표는 차량 관측 좌표가 아닙니다. 역간 보간은 계산임을 유지합니다.
- 첫 인증 검증은 전일·공식 역 코드 한 개·최대 2페이지, 순차·재시도 0회로 제한하는 안을 권장합니다. HTTP 429 또는 원천 `22/23`이면 중단합니다. 전체 수집 예산은 실제 페이지 수와 계정 한도를 확인한 뒤 정하며, 기존 TAGO·서울 예산에 임의 합산하지 않습니다.
- 우선 배치 → 원본/정규화 감사 → 불변 정적 재생 자산 게시 경로를 확장합니다. 현재 실시간 브로커의 `mode: live` 응답에 과거 자료를 넣지 않습니다. R2·D1·정기 실행을 새로 켜거나 연속 수집을 완료로 표시하지 않습니다.

전국이라는 목표만으로 SRT·모든 사업자·화물열차가 포함된다고 가정하지 않습니다. 공급자가 명시한 여객열차 범위에서 역·운행일·차종별 반환 범위를 따로 확인해야 합니다.

## 승인과 다음 검증의 완료 조건

이미 공공데이터포털 일반 키로 TAGO·기상을 연결했다는 사실과 **새 서비스의 활용승인**은 별개입니다. 키를 새로 만들 필요가 있는지보다 해당 키에 연결된 서비스의 승인·사용기간·한도가 먼저입니다. 이번 조사에서 이를 확인하지 않았으므로 KORAIL·각 도시를 승인/미승인 어느 쪽으로도 단정하지 않습니다.
