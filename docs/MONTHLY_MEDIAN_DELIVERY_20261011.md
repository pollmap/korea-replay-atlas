# 월별 중앙값 차트와 후보 목록 개선

관찰일: 2026-10-11 KST. 이 문서는 코드 변경과 공개 반영을 구분한다.

## 변경

- 기본 가격 차트는 선택 전용면적의 월별 거래 중앙값 선이다. 최근 실제 계약과 개별 계약 차트는 별도로 유지한다.
- 여러 정확한 면적을 합칠 때 중앙값의 평균을 계산하지 않는다. 가격별 거래 건수 분포로 실제 가중 중앙값을 구한다.
- 새 요약 생성기는 가격별 건수 분포를 제공한다. 기존 평문·압축 요약 계약과 과거 공유는 계속 읽는다.
- 기존 요약에 분포가 없으면 한 정확한 면적의 저장된 중앙값만 사용한다. 여러 면적이 섞인 월은 기존 제한된 이력 조회를 통해 실제 계약으로 계산한다.
- 원문 보완은 필요한 월만 조회하며 기존 다운로드·파일·보관 상한과 취소 경로를 사용한다. 지도 준비를 기다리게 하지 않는다.
- 원문 건수와 요약 건수가 다르면 중앙값을 확정하지 않는다. 미확인 월·실제 거래 없는 월 사이를 선으로 잇지 않는다.
- 전세와 월세 보증금을 한 선에 섞지 않는다. 거래 유형을 선택해 확인한다.
- 요약 차트의 월 선택은 해당 월 거래표를 연다. 원문 차트의 월 선택은 해당 월 계약 행으로 이동한다. 개별 계약 점과 거래표 연결을 유지한다.
- 단지 비교도 같은 면적·공통 확인 월의 중앙값 선을 제공한다. 기존 요약으로 면적 통합을 계산할 수 없으면 원문 비교를 제공한다.
- 후보 목록은 가격·전용면적을 주소보다 먼저 표시한다. 반복 거래 건수는 기본 축약 목록에서 줄이고 전체 보기에는 유지한다.

## 검증

- 관련 웹 테스트: 8개 파일, 58개 통과.
- 요약 생성·월 묶음 Python 테스트: 21개 통과.
- 타입검사, 린트, 프로덕션 빌드, diff 공백 검사 통과.
- 중앙값·반복 거래·짝수 건·원화 단위·면적별 단가·전세/월세 분리·누락 월·원문 건수 불일치·잘못된 분포·월 선택 조회 범위를 검사했다.
- 실제 화면 검수는 이번 실행의 Windows 브라우저 자동 승인 검토가 현재 URL을 확정하지 못해 중단됐다. 우회하지 않았다. 클릭·초점·화면 배치·체감 지연 통과로 계산하지 않는다.

## 아직 공개되지 않은 범위

이 변경은 브라우저 검수 전 코드 후보다. 대표 Pages의 자료는 `property-ceeff63959643461`이며 새 정정 후보 `property-7f25dea9e9be919f`는 공개 완료가 아니다. 새 가격 분포를 기존 공개 요약이 이미 제공한다고 표현하지 않는다.

## 다음 검수와 공개

1. 1366×768에서 같은 단지·84㎡대·36개월을 연다. 중앙값 선과 최근 실제 계약을 구분한다.
2. 중앙값 월 선택→거래표, 거래 행 선택→개별 점, 기간·면적·단가·전세/월세 전환을 확인한다.
3. 두 단지 비교와 공백 월, 원문 조회 실패·재시도, 키보드 초점과 목록 복귀를 확인한다.
4. 후보 목록·예산·지도 표식의 조건 일치와 모바일 최소 회귀를 확인한다.
5. 공개 PR의 CI와 실제 화면 검수가 모두 통과한 뒤 병합하고 기존 공통 잠금·기대 부모 버전 검사·Pages 후보 검증 순서로 반영한다. `/collection/`과 과거 공유를 보존한다.

## 제품·백엔드 우선순위

| 순서 | 사용자 결과 | 기술 적용 |
|---|---|---|
| 1 | 조건에 맞는 후보가 지도와 목록에 동일하게 보임 | 위치 연결 근거, 공통 조건 식별자, 공간 색인 |
| 2 | 이름·주소 검색으로 후보를 바로 찾음 | 정식 식별자·별칭·주소 정규화, 기존 검색 색인·FTS5의 조회 연결 |
| 3 | 최신 정정 자료가 공개 화면에 반영됨 | 고정 체크포인트, 해시·버전 검사 캐시, 변경 월만 가공, 실패 시 이전 정상본 |
| 4 | 관리비·학교·시설 정보를 근거와 함께 확인 | 단지·주소·기관 ID 관계 테이블, 기준일·검증 상태 |
| 5 | 계획 문서에서 근거를 찾아봄 | 문서·절·페이지·원문 해시 단위 청킹, 먼저 키워드 검색 평가 |
| 후속 | 의미가 유사한 계획·시설 근거를 찾아봄 | 평가 자료에서 개선이 확인될 때만 벡터·재정렬 추가 |

가격·면적·예산·거래기간은 정확한 구조화 필터로 처리한다. 벡터 검색이나 RAG를 수치 계산과 단지 위치 검증의 대체로 사용하지 않는다. 별도 그래프 DB·벡터 DB·유료 모델을 이번 변경에 추가하지 않았다.

`pipeline/property_relations.py`에는 이미 근거·노드·관계·사실·위치 테이블과 FTS5·RTree 생성 코드가 있다. 새로운 그래프 기반을 중복 개발하기보다 실제 자료 연결, 조회 경로, 공개 기능과 운영 범위를 검증한다. 코드가 있다는 이유만으로 모든 단지의 관계·검색이 공개 연결됐다고 판정하지 않는다.
