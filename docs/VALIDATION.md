## API·무료 정적 배포 계약

구현 및 모의/로컬 검사로 확인한 내용:

1. CatalogV2의 작은 목록과 지역 색인을 사용하며 v1 catalog는 사전 생성 파일을 스트리밍합니다. v1 전체 JSON을 Worker에서 해석하지 않는 테스트가 있습니다.
2. 작은 coverage 색인을 사용해 v1 공간·시각 필터와 정확한 matching asset count를 보존합니다. 상위 지역 descriptor 수를 실제 파일 수로 세지 않습니다.
3. 공유에는 데이터 릴리스와 배포 UUID가 들어갑니다. runtime의 잘못된 UUID·외부 호스트 주소를 거부하고 없는 고정 릴리스는 404로 응답합니다.
4. 배포 묶음에 외부 tileset JSON·하위 GLB·지형·기상·검색 shard를 포함합니다. 파일 변경·누락·추가, descriptor SHA/길이 불일치, 총 20,000개 초과·개별 24MiB 이상은 실패합니다.
5. 묶음 ID에 프런트엔드·지도·Worker 코드·헤더 설정을 함께 반영합니다. 기본 설정에 R2/D1·cron이 없고 수집은 비활성입니다.
6. 별도 관측 수집기에서도 공개 catalog를 바로 변경하지 않고 검수 대기 후보만 생성하도록 제한합니다.

Wrangler OAuth와 계정의 Workers Free는 확인했습니다. 인증 미연결 상태는 해소되었습니다. R2의 초과 사용료 청구 계약에는 동의하지 않았고 결제·유료 요금제로 변경하지 않았습니다. 원격 업로드·공개 전환·복구는 아래 증빙으로 별도 판정합니다.
