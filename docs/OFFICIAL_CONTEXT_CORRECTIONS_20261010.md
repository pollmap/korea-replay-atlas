2. 서울 이외 관리비와 세대별/㎡당 관리비. 이번 원천은 서울시 단지 명세 항목입니다.
3. 학교 배정·교육 공시·도보 경로. 이번 연결은 공식 위치와 직선거리입니다.
4. 서버 후보 준비에서 Pages 데이터 업로드·위치 보조자료 재생성·앱 전환까지의 무인 공개. 후보 준비 타이머와 공개 확인 상태를 실제 공개 자동화 완료로 간주하지 않습니다. 장기 게시 자격증명과 해당 파이프라인 연결이 남습니다.
5. 무변경 판정은 준비 실행을 생략하지만, 변경이 있는 날의 모든 월별 산출물을 완전히 증분 생성하는 구조까지 완료하지 않습니다.

### 서비스 계정

호스트의 systemd는 컨테이너의 숫자 UID만으로 실행 계정을 찾지 못할 수 있습니다. 설치 전 `getent passwd 10001`, `getent group 10001`로 기존 계정을 확인합니다. 모두 없을 때만 로그인할 수 없는 `korea-replay-runtime` 시스템 계정·그룹을 UID/GID 10001로 생성합니다. 기존 계정이 있으면 변경하거나 같은 ID를 중복 생성하지 않습니다.

현재 서비스는 이 계정으로 실행하며, 데이터 디렉터리와 기존 압축 저장소를 읽습니다. `/srv/services`·프로젝트 workspaces 조상에는 해당 UID의 통과 권한만 적용했고 다른 프로젝트의 목록·내용 읽기 권한은 추가하지 않았습니다. 키나 압축 원본을 공개 저장소에 저장하지 않습니다.

### Pages 전환 직후 확인

배포 POST가 성공한 직후 대표 주소가 잠시 이전 runtime을 반환한 사례가 있었습니다. `waitForPagesRemote`는 고정된 로컬 산출물을 한 번 검사한 뒤 정상 형식의 이전 runtime에 한해 최대 18회·5초 간격으로 GET 검사합니다. 배포 POST를 다시 보내지 않습니다. 정적 파일 변조·잘못된 응답·권한 오류는 즉시 중단하고, 이미 존재하는 같은 검증 기록은 실제 원격 응답을 다시 검사한 뒤 재사용합니다.

`python3 -B -m pipeline.property_publication_queue --data /srv/services/korea-replay/shared/data --output /srv/services/korea-replay/shared/correction-publication --reserve-bytes 0`

타이머는 하루 한 번과 30분 재시도입니다. 기존 공통 대형 작업 잠금과 자체 큐 잠금을 사용합니다. 수집 장부·원본은 쓰지 않습니다. 공통 잠금이 사용 중이면 중복 실행하지 않고 다음 실행을 기다립니다. 후보 파일·대형 비압축 원본·키를 Git에 넣지 않습니다.

공개 서비스와 개인 collection의 공통 배포 잠금·현재 버전 확인·후보 확인·이전 공유 검증을 유지합니다. 배포 상태와 운영 측정은 작업의 비공개 영수증에 기록합니다.

### 단지 진입의 불필요한 지역 이력 요청

현재 공개 거래 릴리스 `property-ceeff63959643461`에는 지도 가격의 작은 요약이 등록되지 않아 구 전체의 월별 요약을 읽었습니다. 또 1920px 미만에서는 목록이 화면에 보이지 않아도 전체 구 요약을 조회했습니다.

- 같은 공개 릴리스의 SHA·크기를 검증한 단지별 요약으로 서울 25개 구의 지도 가격 파일을 생성했습니다. 기존 위치 연결 832개 단지만 대상으로 하며 새 좌표는 추가하지 않습니다. 전체 2,478,403바이트, 송파구 124,353바이트입니다.
- 2026.9·2026.10, 1·3·6·12·36·60·120·240개월, 전체/국평, 매매/전세/월세 조건을 사전 계산합니다. 다른 월·면적·릴리스는 기존 조회로 돌아가며 다른 조건의 가격으로 대체하지 않습니다.
- 숨겨진 목록은 선택 단지의 요약만 읽어 예산 조건 밖 여부를 확인합니다. 목록을 열거나 넓은 화면에서 목록을 표시하면 지역 요약을 조회합니다. 목록을 보지 않는 동안 다른 단지의 20년 이력을 선행 다운로드하지 않습니다.
- 기존 평문·gzip 자료의 해시 검사를 유지하고 현재 가격 자산도 동일 출처·SHA·1MiB 제한·취소·공통 다운로드 슬롯을 적용합니다. 새 파일은 배포 검사의 닫힌 목록에 크기와 SHA를 고정합니다.
- 로컬 1366px 단지 진입에서 구 전체 월별 묶음 6개가 사라졌고, 선택 단지의 최근 거래 29억·선택 기간 453건은 유지됐습니다. 실제 공개 후보의 조작과 성능 측정은 별도로 확인합니다. 이 요청 감소만으로 첫 지도 2초나 프레임 P95 목표 통과를 선언하지 않습니다.
