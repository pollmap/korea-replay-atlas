## 검증과 판정

- VPS 리눅스에서 웹 테스트 1,225개, 타입·린트·프로덕션 빌드 통과.
- 후보·공식 자료·기존 게시기 관련 Python 검사 51개 통과. 이후 보강한 무변경/세대 보호 검사는 별도로 실행합니다.
- PC 실제 조작: 헬리오시티 관리비 27개 항목 펼침, 공식 학교 반경 1km 11개 기록 → 초등학교·500m 1개, 거래·국평·36개월 조건 유지 확인.
- 로컬 SSH 프록시의 첫 진입은 실제 공개 환경보다 느려 공개 성능 달성 근거로 사용하지 않습니다. 첫 지도 2초·지역 P95 1초·프레임 P95 33ms 통과 여부는 공개 후보 측정으로 판정합니다.
- Windows 전체 검사의 기존 배포 테스트는 제한시간/파일 잠금으로 실패했지만 같은 검사 28개가 Linux에서 통과했습니다. 새 TS 테스트의 타입 오류는 수정했습니다.

## 아직 완료가 아닌 것

1. 지정 권역 모든 단지의 위치·경계 검증. 초기 진입 수정은 기존 검증 위치만 사용하며 새 위치를 추정하지 않습니다.
2. 서울 이외 관리비와 세대별/㎡당 관리비. 이번 원천은 서울시 단지 명세 항목입니다.
3. 학교 배정·교육 공시·도보 경로. 이번 연결은 공식 위치와 직선거리입니다.
4. 서버 후보 준비에서 Pages 데이터 업로드·위치 보조자료 재생성·앱 전환까지의 무인 공개. 후보 준비 타이머와 공개 확인 상태를 실제 공개 자동화 완료로 간주하지 않습니다. 장기 게시 자격증명과 해당 파이프라인 연결이 남습니다.
5. 무변경 판정은 준비 실행을 생략하지만, 변경이 있는 날의 모든 월별 산출물을 완전히 증분 생성하는 구조까지 완료하지 않습니다.
