자료를 화면에 올리는 기준은 세 가지입니다. 신고 거래는 국토교통부의 계약월·거래 유형·취소 상태를 함께 표시합니다. 서울시 공동주택 점은 K-apt 코드가 기존 공식 목록과 일치한 2,780개만 탐색 후보로 사용하며, 원천에서 좌표계와 점의 의미를 명시하지 않아 정확한 건물 위치로 선언하지 않습니다. 서울시 도로명주소와 국토부 매매 원문 2025-09~2026-08 76,757행을 원본 SHA 확인 후 대조했습니다. 서울시 2,893행 중 주소·이름·상호 유일성·게시된 단지 ID가 모두 일치한 860건 가운데, 기존 K-apt 공식 목록과 점까지 일치하는 **848건**만 지도 점→실거래 패널로 연결했습니다. 주소가 겹치거나, 이름이 다른 단지는 자동 채택하지 않습니다. 이 가운데 847개는 게시된 12개월 거래 파티션의 SHA와 행수를 다시 확인하고, 취소·검토 거래를 제외한 **가장 최근 한 건**의 가격·면적을 지도에 표시합니다. 같은 단지의 면적별 가격이나 시세가 아니라 한 건의 신고 사례입니다. 예를 들어 헬리오시티는 서울시·K-apt 도로명주소와 국토부 원문 `송파대로 345`, 단지명, 지역 코드가 맞아 연결됩니다. 국토부 지번 `913`과 K-apt 기본정보 지번 `479`의 불일치는 그대로 기록하고 지번 일치라고 주장하지 않습니다. 점은 계속 **후보 좌표**이며 확정된 건물 경계로 표시하지 않습니다. 출처는 [서울시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/A/1/datasetView.do)와 [국토교통부 아파트 매매 신고상세](https://www.data.go.kr/data/15126468/openapi.do)입니다.

12개월 완료 계약월의 수집 슬롯은 현재 256개 지역 코드 기준으로 확인했고 새 불변 데이터 후보에 게시했습니다. 이전 행정구역의 코드 대응은 아직 완성되지 않았으며, 전국 아파트의 모든 과거 거래·모든 단지 위치를 확보했다는 뜻이 아닙니다. 화면 속 ‘전국’은 서비스 탐색 범위이고, 지표·단지점의 확보 범위는 각각 표시해야 합니다.
