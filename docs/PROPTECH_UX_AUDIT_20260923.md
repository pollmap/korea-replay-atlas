# 지도 중심 부동산 대시보드: 화면 흐름 감사

2026-09-23 기준, 데스크톱 1280×720에서 [호갱노노](https://hogangnono.com/), [아실](https://asil.kr/asil/index.jsp), KOREA REPLAY의 전국 화면과 단지 상세 진입을 직접 비교했습니다. 두 서비스의 디자인·데이터를 복제하는 문서가 아니라, 관찰한 사용자 동작을 우리 공식 자료와 연결하기 위한 기록입니다. 모바일·로그인 전용·유료 기능의 전체 목록을 검증한 결과가 아닙니다. 캡처 증빙은 비공개 작업 디렉터리 `.local/ux-audit-20260923/`에 보관합니다.

자료를 화면에 올리는 기준은 세 가지입니다. 신고 거래는 국토교통부의 계약월·거래 유형·취소 상태를 함께 표시합니다. 서울시 공동주택 점은 K-apt 코드가 기존 공식 목록과 일치한 2,780개만 탐색 후보로 사용하며, 원천에서 좌표계와 점의 의미를 명시하지 않아 정확한 건물 위치로 선언하지 않습니다. 국토부 `aptSeq`와 K-apt 코드는 단지명만으로 연결하지 않으므로 가격 말풍선을 만들지 않습니다. 출처는 [서울시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/A/1/datasetView.do)입니다.

12개월 완료 계약월의 수집 슬롯은 현재 256개 지역 코드 기준으로 확인했고 새 불변 데이터 후보에 게시했습니다. 이전 행정구역의 코드 대응은 아직 완성되지 않았으며, 전국 아파트의 모든 과거 거래·모든 단지 위치를 확보했다는 뜻이 아닙니다. 화면 속 ‘전국’은 서비스 탐색 범위이고, 지표·단지점의 확보 범위는 각각 표시해야 합니다.

릴리스 인수는 화면이 닮아 보이는지와 별개로 판단합니다. 지도 처음 준비, 2D 이동 프레임 P95, 단지 선택, 뒤로가기, 모바일 패널, 2D↔3D 복귀, 공개 URL의 버전 고정과 누락 파일 404를 검증합니다. 성능 목표에 미달하면 후보 주소를 유지하고 대표 주소를 교체하지 않습니다.
