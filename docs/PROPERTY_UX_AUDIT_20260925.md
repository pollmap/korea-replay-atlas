## 흐름별 결과

1. **지역 → 단지: 개선.** 조건이 적용돼도 점만 보여 어떤 범위인지 다시 열어야 했습니다. 가격·면적·건축연도·법정동·검색어를 해제 가능한 칩으로 표시합니다. 거래 미확인 상태와 실제 0건을 유지하면서 선택 월에 유효 거래가 있는 단지만 추릴 수 있습니다.
2. **단지 → 가격: 개선.** 상단의 지역 선택·반복 주소·좌표 설명을 정리했습니다. 주소·건축연도는 한 줄, 위치의 근거는 단지정보에 둡니다. 실거래·단지정보·출퇴근·비교 탭은 스크롤 영역 밖에 유지합니다.
3. **조건 → 차트: 개선.** 면적·기간을 가격 위에 배치하고 좁은 화면의 일곱 기간 버튼을 선택 상자로 바꿨습니다. 차트의 가격/거래량과 총액/전용평당/전용㎡당 기준을 한 줄에 모았습니다. 평당·국평 지표와 계산 설명은 차트 아래에서 확인합니다.
4. **정보 → 출퇴근: 개선.** 해당 탭에서 관련 없는 거래 유형·계약월·원문 표 버튼을 표시하지 않습니다. 출처와 미검증 좌표의 상태는 단지정보에서 계속 확인할 수 있습니다.
5. **모바일: 개선, 장기 사용 검증 필요.** 390×844에서 기존 첫 가격 영역이 y=907px 아래에 있어 접힌 상세에서 보이지 않았습니다. 변경 화면은 같은 상태에서 첫 가격을 보이게 하고, 전체 높이에서 저장·비교·위치 도구를 제공합니다. 확대 글꼴·보조기기 전체 조합의 접근성 인증을 주장하지 않습니다.

## 검증 기준

- 필터 편집 진입 시 첫 입력으로 초점 이동, Escape 시 편집을 닫고 해당 필터 버튼으로 복귀.
- 역전 범위는 오류를 표시하고 결과 확인 버튼 비활성화. 개별 조건 해제 시 다른 조건·정렬 보존.
- 미확인 자료에 거래 필터를 적용해도 0건으로 숨기지 않음. 취소·무효 거래만 있는 단지는 검증 후 제외.
- 실제 헬리오시티의 2026.06–08, 전용 84㎡대 선택 후 13건으로 필터, 기존 신고 금액 유지.
- 모바일 접힘/전체, 정보/출퇴근, 목록 복귀, 면적·기간·차트 기준 전환 확인.
- 자동 검증은 기존 공개 CI의 타입·린트·테스트·빌드·소스 감사에 새 필터 회귀 검사를 추가.
