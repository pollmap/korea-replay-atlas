# 전세·월세 조건 일치 — 2026-09-26

아파트 2D 화면의 전월세를 `전체 / 전세 / 월세`로 나눕니다. 월세가 0원인 계약만 전세, 0원 초과인 계약만 월세입니다. 미제공·음수·비정상 값은 전세로 바꾸지 않습니다. 기존 매매·과거 공유 링크는 기존 동작을 유지합니다.

## 사용자 흐름

- 지역 목록, 단지 상세의 거래 점·표·CSV, 전용 평당 보증금·84㎡대 보증금, 단지 비교가 같은 유형 조건을 사용합니다.
- 단지 비교는 선택 계약월 1개월, 상세 이력은 사용자가 고른 기간입니다. 두 화면 모두 기간·표본 수를 표시합니다.
- 검색조건 저장·JSON 내보내기/가져오기, URL 복원과 뒤로가기에 유형이 포함됩니다. 매매에서는 임대 유형을 적용하지 않습니다.
- 유형 변경은 이미 받은 거래를 필터링합니다. 자료 요청 키를 변경하거나 지도를 재생성하지 않습니다.
- 전국 지도 표지와 지역 월별 집계는 기존 게시 통계인 **전월세 전체**입니다. 상세 필터 결과로 오인하지 않도록 전체 기준을 명시합니다.
- 월세 보증금과 월 납부액은 함께 봐야 합니다. 월세 중앙값과 보증금 중앙값은 각각의 통계이며 특정 하나의 계약이나 환산 전셋값이 아닙니다.

## 검증

- 전체 웹 테스트 922개/71개 파일 통과, 린트·타입검사·프로덕션 빌드 통과.
- 새 회귀 검사: 명시적 0과 미제공 구분, 목록/이력/가격 동일 선택, 미확인 자료 보존, 잘못된 공유값 처리, 저장조건 왕복과 잘못된 enum 거부.
- 공개 자료 릴리스 `property-eea48453a819f517`의 실제 헬리오시티 2026.06–08: 전세 117건, 월세 195건, 전체 312건. 월세 84㎡대는 58건; 2026.08 단월 비교는 23건으로 각각 해당 기간 기준.
- 390×844 모바일: 유형 버튼 높이 44px, 가로 넘침 없음, 접힌 패널에서도 첫 보증금 표시. 전체 높이로 확장해 기록을 탐색합니다.

## 범위

이번 변경은 3D 렌더러·원본 자료·공개 거래 릴리스를 변경하지 않습니다. 새 데이터 수집 완료, 전국 10년 이력 완료 또는 경쟁 서비스 전체 기능 동등성을 뜻하지 않습니다. 단지 기본정보·검색조건 저장의 이전 변경은 PR #33으로 머지·공개 배포됐으며 공개 파일 응답 15개 표본을 통과했습니다.
