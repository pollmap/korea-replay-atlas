기준일: 2026-09-20 KST. 최신 데이터 미리보기는 공개됐고 새 Pages 앱은 아직 미공개입니다. 공개 소스 PR #1·#2는 병합됐으며 모바일 저줌 수정 PR은 준비 중입니다. 이 문서는 구현, 원천 수집, 데이터 배포, 앱 공개를 별도로 판정합니다. 기존 KOREA REPLAY의 3D 자료와 운영 주소는 보존합니다.

- 새 대표 주소로 `korea-replay.pages.dev` 프로젝트를 확보했습니다. 통합 앱은 아직 미공개이며 실제 공개 전환·응답 검증이 남아 있습니다. 프로젝트 존재나 예정 주소를 앱 배포 성공으로 취급하지 않습니다.

기존 비공개 저장소 이력에 개인 경로와 과거 계정 주소가 있어, 원래 저장소는 그대로 보존하고 같은 프로젝트의 검사된 소스를 새 공개 저장소에 원격화했습니다. 기존 이력을 강제로 다시 쓰거나 원본을 삭제하지 않았습니다. 자체 코드의 MIT 라이선스는 외부 데이터의 이용허락을 대체하지 않습니다.

## 작동하는 사용자 흐름

전국 거래량 목록 → 지역 → 계약월/거래유형 → 단지 → 정확히 같은 전용면적 → 거래 점·원문·CSV를 연결했습니다. 최대 3개 지역과 3개 단지를 비교하며 미수집과 실제 0건을 구분합니다. 공식 좌표가 없는 단지의 지도 이동 버튼은 제공하지 않습니다.

로컬 통합 앱은 2D를 기본으로 열고, 3D는 전환할 때만 로드합니다. 전국 검색, 지도 전체 보기, 거리·면적 측정, 경계 표시, 위치 조회, 기기 내 즐겨찾기 가져오기/내보내기를 구현했습니다. 햇빛·기록 도구는 기존 기능으로 보존합니다. 새 Pages 앱에서의 공개 사용자 흐름 검증은 남아 있습니다.

## 성능·화면 검증의 범위

- 로컬 프로덕션 빌드 첫 2D 진입에서 Cesium·3D GLB·지형 요청이 없었습니다.
- 전국 카메라에서 2D↔3D를 20회 빠르게 왕복한 43개 표본 모두 캔버스 1개, 오류 알림 0개였습니다. 각 엔진에서 최소 12 애니메이션 프레임을 기다린 생명주기 검사이며 장시간 도시 탐색의 메모리 누수 판정은 아닙니다.
- 위 검사에서 JS heap은 약 15.8~283.0MB 사이를 오르내리며 회수됐습니다. GPU 메모리·장시간 안정성·총 브라우저 메모리와 구분합니다.
- 서울↔부산 20회 왕복과 인천·제주·울릉·독도 검사 44개 표본에서 캔버스 최대 1개, 오류 0개, 타일 요청 동시성 최대 4개였습니다. 묶음 캐시 최대 23,496,093바이트, JS heap 최대 208,688,024바이트·마지막 115,813,123바이트를 확인했습니다. 업로드가 함께 실행된 마지막 이동 프레임 P95는 **37.60ms**로 33ms 목표를 충족한 증거가 아닙니다.
- 이전 모바일 CSS 390×844 검사에서는 가로 넘침 없음, 중간 패널 40dvh, 주요 조작 버튼 44px를 확인했습니다. 이후 새 진입에서 전국 fitBounds 줌이 5 미만인데 모든 MVT 주제가 minzoom 5 이상이어서 아카이브 요청 0개·바다만 표시되는 오류가 발견됐습니다. 육지·시도의 minzoom 3 데이터와 화면 여백 수정이 모바일 PR 준비 범위이며, 기존 CSS 검사만으로 이 오류가 해결됐다고 판정하지 않습니다.
- 20Mbps·50ms·초기/재방문 캐시 각각 10회, 첫 표시 **2초**, 도시 왕복 프레임 P95, 검색 P95, **10배 개선**은 아직 달성 판정하지 않았습니다. 배치·업로드가 함께 실행된 임시 수치를 통제된 성능 결과로 발표하지 않습니다.
- 이전 로컬 소스 시점의 타입·린트·프로덕션 빌드와 웹 782개, Python 716개 회귀가 통과했습니다. Python 1개 검사는 사유가 있는 건너뜀으로 별도 기록합니다. 이후 공개 PR #1의 검사와 이번 저줌 변환 관련 Python 60개·실물 JS/원격 MVT 검증은 각각 다른 시점·범위의 증거이며 전체 최신 검사 수로 합산하지 않습니다.

## 배포와 복구

앱과 데이터는 별도 Pages 프로젝트이며 앱은 실제 불변 데이터 배포 URL과 manifest SHA를 고정합니다. 지도 파일은 정적으로 제공하고 `/api/*`만 함수로 처리합니다. 미리보기 검증 이후에만 대표 주소로 전환합니다. [배포 절차](PAGES_DEPLOYMENT.md)를 따르며 Wrangler의 원격 Pages 명령은 사용하지 않습니다.

코드 저장소만으로 대용량 원본과 모든 과거 지도 파일이 복구되지는 않습니다. 기존 로컬 원본, 수집 장부, 불변 배포 묶음과 비공개 인증 파일을 보존해야 합니다. 게시된 지도는 노트북을 꺼도 제공되지만, 로컬에서 실행하는 수집·재타일링은 노트북이 켜져 있어야 합니다. 원본 보관과 정기 수집의 서버 운영 전환은 별도 완료 조건입니다.

무료 한도는 프로젝트당 20,000파일·파일당 25MiB이며 내부 검사는 24MiB, MVT 묶음은 1MiB 상한을 적용합니다. [Cloudflare 공식 한도](https://developers.cloudflare.com/pages/platform/limits/)

이번 새 Pages 앱의 공개 전환과 이전 정상 Pages 앱으로의 롤백은 아직 확인되지 않았습니다. 기존 Worker 복구 검증과 새 서비스의 롤백 검증을 혼동하지 않습니다. **60개 완료월 수집, 전국 모든 위치의 정확성, 2초·10배 성능 목표, 새 Pages 앱 롤백을 완료로 보고하지 않습니다.**

대용량 앱 업로드 두 차례가 약 30분 뒤 HTTP 403으로 중단됐습니다. 원인은 확정하지 않았습니다. 인증 토큰 만료 전 갱신을 추가하고, 서버가 수락한 버킷의 정확한 해시만 즉시 등록해 중단 후 재사용할 수 있도록 보완했습니다. 과거 진행 건수로 파일 성공을 추정하지 않으며 재시작 시 서버의 `check-missing` 응답을 따릅니다. 부분 자산 등록은 대표 주소를 변경하지 않습니다.
