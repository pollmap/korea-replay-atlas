## 성능·화면 검증의 범위

### Production 전국 2D 지도 준비 시간

`final-production-2d-performance.json`의 **21표본**을 재계산했습니다. 최초 진입 10회, 재방문 준비 1회, 재방문 10회이며 준비 1회는 통계에서 제외합니다. 시간은 **navigation 시작 → 지도 idle이며 필요한 타일 로딩 완료**까지입니다. 첫 픽셀 표시나 속도 개선 배율의 측정은 아닙니다.

| 구분 | 표본 | 중앙값 | P95 | 최댓값 |
|---|---:|---:|---:|---:|
| 최초 진입: HTTP 캐시 사용 안 함 | 10회 | 1,147.0ms | 1,160.2ms | 1,160.2ms |
| 재방문: HTTP 캐시 사용·1회 준비 후 | 10회 | 535.2ms | 944.3ms | 944.3ms |

P95는 정렬한 `ceil(0.95×n)`번째 값인 nearest-rank 방식입니다. 10표본에서는 최댓값과 같습니다. 조건은 Radeon 860M, 전경 CSS 1280×720·DPR 2·실제 캔버스 1920×1080, 전원 Balanced/AC, 다운로드·업로드 20Mbps·지연 50ms입니다. 수집·빌드·업로드·감사는 정지했고 다른 사용자 앱은 바꾸지 않았습니다. 같은 브라우저 renderer 프로세스를 사용했으므로 매번 브라우저·GPU 캐시까지 초기화한 실험은 아닙니다.

집계한 20회 모두 `visible`, 기록된 지도 오류·오류 알림 0, 초기 3D 엔진·GLB·지형 요청 0을 확인했습니다. **이 조건의 전국 초기 지도 준비는 2초 이내**였습니다. 교차 출처 응답에 `Timing-Allow-Origin`이 없어 브라우저 리소스 기록의 바이트 합계를 전체 전송량으로 해석하지 않습니다. 다른 기기·이동통신 환경이나 상세 도시의 준비 시간으로 일반화하지 않습니다.

### 이동 프레임과 이전 검사의 한계

- `final-pages-city-probe.json`은 3D 왕복 이후 서울↔부산 **30이동·15왕복**을 관찰한 비통제 표본입니다. 배포 파일 해시 검사가 병행됐고 네트워크 속도를 제한하지 않았습니다. 마지막 이동 프레임 P95는 최근 **600프레임 기준 38.2ms**로 33ms 목표를 충족하지 못했습니다. 전체 30이동을 합친 P95가 아닙니다.
- 통제 조건의 production 서울↔부산 **20왕복·40표본**은 `final-production-city-20-roundtrips.json`으로 별도 확인했습니다. Radeon 860M·CSS 1280×720·DPR 2·실제 1920×1080, 20Mbps/50ms, Balanced/AC이며 수집·빌드·업로드·감사를 멈췄습니다. 최종 최근 **600개 이동 프레임 P95 39.2ms**, 40개 관찰 창의 P95 최댓값 **39.4ms**로 **33ms 목표 미달**입니다. 단일 프레임 최댓값이나 전체 40이동의 통합 P95를 뜻하지 않습니다.
- 위 40표본의 지도 오류·오류 알림은 0, 캔버스는 항상 1개, 타일 요청 동시 최대는 4개였습니다. 관찰된 JS heap은 최대 **129,563,202 B**·최종 **62,449,625 B**, 묶음 캐시는 최대·최종 **11,392,504 B**·아카이브 78개였습니다. JS heap이 회수된 표본이며, GPU/전체 프로세스 메모리나 장시간 누수 부재를 증명하지 않습니다.
- 이전 로컬 2D↔3D 20왕복의 43표본은 캔버스 최대 1개·오류 알림 0개였습니다. 서울↔부산과 섬 지역의 44표본에서는 요청 동시 최대 4개를 확인했으나 업로드 병행 이동 P95 37.60ms는 목표 통과 증거가 아닙니다. 이 생명주기·자원 표본을 GPU 메모리나 장시간 누수 검증으로 확대하지 않습니다.

## 배포와 복구

앱과 데이터는 별도 Pages 프로젝트이며 앱은 실제 불변 데이터 배포 URL과 manifest SHA를 고정합니다. 지도 파일은 정적으로 제공하고 `/api/*`만 함수로 처리합니다. 미리보기 검증 이후에만 대표 주소로 전환합니다. [배포 절차](PAGES_DEPLOYMENT.md)를 따르며 Wrangler의 원격 Pages 명령은 사용하지 않습니다.

코드 저장소만으로 대용량 원본과 모든 과거 지도 파일이 복구되지는 않습니다. 기존 로컬 원본, 수집 장부, 불변 배포 묶음과 비공개 인증 파일을 보존해야 합니다. 게시된 지도는 노트북을 꺼도 제공되지만, 로컬에서 실행하는 수집·재타일링은 노트북이 켜져 있어야 합니다. 원본 보관과 정기 수집의 서버 운영 전환은 별도 완료 조건입니다.

무료 한도는 프로젝트당 20,000파일·파일당 25MiB이며 내부 검사는 24MiB, MVT 묶음은 1MiB 상한을 적용합니다. [Cloudflare 공식 한도](https://developers.cloudflare.com/pages/platform/limits/)

새 Pages 앱의 공개 전환은 확인했지만 **이전 정상 Pages production으로 실제 롤백한 뒤 최종판으로 복귀하는 검증은 미완료**입니다. 기존 Worker의 복구·복원 검사로 이를 대신하지 않습니다. 최근 60개 완료월 수집, 과거 행정 코드 대응, 단지 공식 좌표 연결, 공식 인구·공급·가격지수, 최신 관측의 연속 수집, 전국 정확성·10배 성능과 외부 원본 백업도 미완료입니다. 로컬 원본·수집 장부·배포 묶음을 정리할 조건을 충족하지 않았습니다.

대용량 앱 업로드 두 차례가 약 30분 뒤 HTTP 403으로 중단됐던 원인은 확정하지 않았습니다. 인증 토큰 만료 전 갱신과 성공 버킷의 정확한 해시 등록을 보완한 뒤, 최종 후보·production은 위와 같이 대부분 또는 전부 재사용해 게시했습니다. 과거 진행 건수로 파일 성공을 추정하지 않으며 재시작 시 서버의 `check-missing` 응답을 따릅니다. 부분 자산 등록 자체는 대표 주소를 변경하지 않습니다.
