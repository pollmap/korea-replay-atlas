## 이번 적용과 검증

- 법정동 선택을 URL·공유·브라우저 탐색 상태에 포함했습니다. 단지 상세에서 `← 가락동 아파트`로 돌아가면 가락동 목록과 조건을 유지합니다. 상세의 `가락동 아파트 보기 →`로도 해당 동 목록에 진입합니다.
- 구 변경 시 이전 법정동을 해제하고, 연결되지 않은 동을 전체 목록으로 조용히 대체하지 않습니다. 구 전체 지표에는 구 이름과 `전체`를 붙여 동 통계로 오인하지 않게 했습니다.
- 로컬 프로덕션 빌드에서 송파구 → 가락동 84개 단지 → 헬리오시티 → 가락동 84개 단지 복귀를 실제 조작해 확인했습니다. 단지정보에는 동일한 신고 주소를 이용하는 네이버·카카오 지도 링크가 표시됩니다.
- 2D 진단 수집의 매 프레임 집계를 250ms 간격으로 제한하고 유휴 상태에서 마지막 값을 반영합니다. 결정론적 검사에서 120회 요청의 집계 횟수는 5회였습니다. 이 값은 실제 GPU 프레임 속도나 서비스 전체 10배 개선 수치가 아닙니다.
- 관련 회귀를 포함해 1,002개 테스트·타입검사·린트·프로덕션 빌드를 통과했습니다. 실제 후보 및 공개 배포 검증은 배포 영수증과 별도 브라우저 기록으로 관리합니다.
