# 실거래 차트와 계약 기록 연결

## 공개 화면 관찰 (2026-09-26 KST)

- [호갱노노 헬리오시티](https://hogangnono.com/apt/aAh37/0): 면적·거래 유형·기간 선택과 그래프, 계약일·면적·가격·층을 담은 거래 표, 더보기 동작의 진입점을 확인했습니다.
- [아실](https://asil.kr/asil/index.jsp): 지도와 지역 단계, 가격·면적 필터, 아파트 검색과 비교 분석 진입점을 확인했습니다.
- [네이버 부동산](https://new.land.naver.com/complexes): 아파트·오피스텔, 가격·면적 필터, 지역 선택, 가격 표지와 지도·목록 바로가기를 확인했습니다.

이번 관찰은 공개된 위 화면 범위입니다. 모든 상세 화면 검토나 경쟁사의 차트-표 양방향 선택 기능 확인을 의미하지 않습니다. 거래 조건·그래프·계약 기록의 가까운 배치와 직접 이동 조작을 참고해 아래 개선을 설계했습니다.

## 해결한 불편

기존 화면은 차트에서 과거 거래를 골라도 계약 표에는 처음 12건만 보였습니다. 같은 기록을 찾으려면 더보기를 누르고 날짜·층·가격을 수동 대조해야 했습니다.

- 이전·다음 거래 버튼으로 작은 차트 점을 정확히 누르지 않고 이동합니다.
- `계약 기록 보기`는 선택된 원본 행 ID의 기록까지 표를 확장하고 해당 버튼에 초점을 둡니다.
- 표의 계약일 버튼은 가격 차트로 돌아가 동일 기록을 선택합니다. 거래량 차트에서도 가격 차트로 복귀합니다.
- 선택 행을 색과 왼쪽 선으로 표시합니다. 날짜·가격·면적이 같은 서로 다른 거래는 원본 행 ID로 구분합니다.
- 탐색 버튼 높이는 44px이며 처음·마지막 거래의 진행 불가능한 방향은 비활성화합니다.

거래 수집 범위, 집계 방식, 3D 코드·데이터는 변경하지 않았습니다.

## 검증

- 단위 회귀: 숨겨진 24번째 기록 노출, 이미 확장한 표 보존, 내용이 같은 별개 거래, 필터에서 제외된 ID.
- 프로덕션 빌드의 실제 브라우저: 헬리오시티 2026.06–08의 24건 중 6월 1일 차트 → 24번째 기록 초점 → 차트 복귀, Enter로 다음 거래 이동, 거래량 화면에서 표 → 가격 차트 복귀.
- 1280×720 화면에서 버튼 겹침과 44px 높이를 확인했습니다. 이번 검증만으로 모바일 전체 흐름 통과나 성능 목표 달성을 주장하지 않습니다.
