## 지도 문자 대비

11px 노선·역 이름은 선과 같은 노란색을 그대로 쓰면 흰색 halo 대비가 약 1.586:1에 불과합니다. 선·역 테두리의 공식 표시색은 유지하고 문자에만 같은 색 계열의 어두운 색을 적용합니다.

- 기준: [W3C WCAG 2.2 SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)의 일반 문자 최소 4.5:1. 계산한 대비는 반올림해서 통과시키지 않습니다. 8비트 sRGB를 선형화할 때 분기점은 0.04045이며 상대휘도 계수는 0.2126·0.7152·0.0722입니다. 흰색 대비는 `1.05 / (L + 0.05)`로 검사합니다.
- 기존 대비가 4.5:1 이상이면 원래 색을 유지합니다. 미달이면 검정과 혼합해 같은 색 계열을 보존하면서 5:1을 목표로 어둡게 합니다. 작은 글자의 여유를 확보하기 위한 목표이며 전체 서비스의 WCAG 준수를 의미하지 않습니다.
- 색 변환은 모듈 초기화 때 고유 팔레트에 한 번만 수행합니다. 피처·프레임마다 변환하지 않습니다. MapLibre에서는 기존 노선 식별 결과를 작은 고정 `match` 표로 문자색에 연결합니다. 선로 이름 제외 필터도 ID `match`를 사용합니다.
- source ID·노선 판정·공용선 중립 규칙은 동일합니다. 미확인 철도는 어두운 중립색을 사용하고, 새로운 노선색으로 추정하지 않습니다.
