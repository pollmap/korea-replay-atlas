# KOREA REPLAY Atlas

대한민국 전국 지도와 출처 기반 지역·부동산 탐색 프로젝트의 공개 소스입니다.

기존 KOREA REPLAY의 3D 지도·교통·기상 기능을 유지하면서 빠른 2D 지도와 지역·아파트 분석을 추가합니다. 자체 코드는 MIT로 제공하며 외부 데이터는 각 원천 이용조건을 따릅니다.

개인 계정 배포 주소가 포함된 기존 Git 이력과 원본 대용량 자료는 비공개 보관소에 보존했습니다. 이 공개 저장소는 개인정보·비밀키 검사를 거친 동일 프로젝트 소스의 배포 지점입니다. 원격 소스 보관과 데이터 백업은 별도로 관리합니다.

통합 구현은 검증된 PR로 추가합니다. 미수집 자료나 측정하지 않은 성능을 완료로 표시하지 않습니다.
